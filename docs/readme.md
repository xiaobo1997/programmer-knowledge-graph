# 总目录

> 点击分类胶囊筛选该分类内容。点击文章直接阅读。

<TocOverview />

## 使用方式

- 顶部胶囊筛选：点「全部」或任意分类名 → 只显示该分类的文章
- 点分类标题 → 进入该分类目录页（左侧栏自动展开）
- 点文章标题 → 直接阅读
- 顶部 `⌘ K` → 全站全文搜索
- 左侧「知识分类」→ 按分类快速切换

## 沉淀原则

- 一篇文章对应一个具体知识点或阅读心得，不写大杂烩
- 每篇至少包含：核心观点、个人思考、行动清单
- 图示尽量用 Mermaid 或 SVG，避免外部链接失效
- 写到 1000 篇左右时考虑 Pagefind 替换 VitePress 内置搜索
