# 总目录

这里是整个 `docs/` 目录的总目录，会随内容更新自动变化。

## 如何使用

- 左侧「知识分类」是按大类组织的导航
- 顶部搜索（`⌘ K`）支持标题与正文的中文搜索
- 每篇文章显示预计阅读时间、字数、最后更新日期
- 阅读时按 `↑` 返回顶部、按 `⌘ K` 搜索、按 `1` 切换明暗主题

## 专题

文档内容会按以下分类组织。每新增一篇文章，先在对应目录下创建文件，文件名建议带前缀编号便于排序：

```
docs/reading-notes/书籍名-简短主题.md
docs/fullstack/前端-主题.md
docs/devops/工具-主题.md
docs/agent/agent-主题.md
docs/roadmap/技术地图-主题.md
```

## 沉淀原则

- 一篇文章对应一个具体知识点或阅读心得，不写大杂烩
- 每篇至少包含：核心观点、个人思考、行动清单
- 图示尽量用 Mermaid 或 SVG，避免外部链接失效
- 写到 1000 篇左右时考虑 Pagefind 替换 VitePress 内置搜索
