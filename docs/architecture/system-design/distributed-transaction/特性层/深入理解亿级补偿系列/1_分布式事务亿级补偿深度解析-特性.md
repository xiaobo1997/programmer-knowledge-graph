# 分布式事务亿级补偿机制

> 本篇深入分布式事务的补偿机制：SAGA 幂等设计、资损对账体系、亿级订单场景下的补偿策略。

## 一、本文核心

分布式事务补偿 = 幂等设计 + 资损对账 + 分片补偿

核心机制：SAGA 协调器 + 补偿链 + 对账体系

## 二、核心机制原理穿透

### 2.1 幂等性保证

```
幂等性保证机制：

  1. 唯一事务 ID
     → 每个事务分配唯一 ID
     → 重复执行同一事务 ID → 跳过
     → 实现方式：Redis setnx / 数据库唯一索引

  2. 状态机
     → 事务有明确状态：init → doing → done / rollback
     → 状态转换不可逆
     → 重复执行 → 当前状态已确认 → 跳过

  3. 乐观锁
     → 版本号/时间戳
     → 更新时检查版本号
     → 版本不匹配 → 重试或放弃
```

### 2.2 SAGA 补偿架构

```
SAGA 补偿架构：

  ┌──────────┐    ┌──────────┐    ┌──────────┐
  │  服务 A    │───>│  服务 B    │───>│  服务 C    │
  │ (正向下单) │    │ (正向下库存)│    │ (正向下支付)│
  └──────────┘    └──────────┘    └──────────┘
       ↑               ↑               ↑
       │ 补偿          │ 补偿          │ 补偿
       │ (取消订单)     │ (恢复库存)     │ (退款)
       
  协调器：
    ├── 记录正向操作日志
    ├── 记录补偿操作日志
    ├── 失败时触发补偿链
    └── 补偿链：反向执行补偿操作
```

## 三、关键参数与边界条件

### 3.1 补偿参数

| 量级 | 补偿策略 | 重试次数 | 重试间隔 | 死信阈值 |
|---|---|---|---|---|
| 十万 QPS | 同步补偿 | 3 | 1s | 3 次 |
| 百万 QPS | 异步补偿 | 5 | 5s | 5 次 |
| 千万 QPS | 异步 + 批量 | 10 | 10s | 10 次 |
| 亿级 QPS | 异步 + 批量 + 分片 | 20 | 30s | 20 次 |

### 3.2 分片补偿

```
分片补偿策略：

  1. 按时间分片
     → 每小时/每天一个分片
     → 并行补偿多个分片
     → 分片大小 = 1000-10000 条

  2. 按 Key 分片
     → 按订单 ID hash 分片
     → 每个分片独立补偿
     → 避免重复补偿

  3. 优先级分片
     → 核心交易优先补偿
     → 非核心交易延迟补偿
     → 优先级 = 金额 + 业务类型
```

### 3.2 超时补偿

```
超时补偿策略：

  1. 超时检测
     → 正向操作超时 → 触发补偿
     → 超时阈值 = 正常耗时 × 3

  2. 超时补偿
     → 执行反向操作
     → 记录补偿日志
     → 通知人工确认

  3. 超时重试
     → 补偿失败 → 重试
     → 重试次数 = 3-5 次
     → 重试间隔 = 指数退避
```

## 四、生产事故与排查

### 事故 1：补偿幂等失效

**场景**：某系统补偿操作非幂等，重复补偿导致数据错误。

**现象**：
- 订单被重复取消
- 库存被重复恢复
- 账务数据不一致

**根因**：
- 补偿操作无幂等检查
- 网络超时导致重复触发补偿
- 补偿重试无幂等保护

**修复**：
1. 补偿操作加幂等检查（唯一事务 ID）
2. 补偿前检查状态（状态机）
3. 补偿记录表（记录已补偿的事务）

### 事故 2：对账遗漏

**场景**：某系统对账任务遗漏部分数据。

**现象**：
- 对账结果不一致
- 差异数据未补偿
- 账务对不平

**根因**：
- 对账范围不全
- 对账时间窗口遗漏
- 对账任务失败未重试

**修复**：
1. 对账范围覆盖全量数据
2. 对账时间窗口连续无遗漏
3. 对账任务失败自动重试
4. 对账结果人工确认

## 五、业内惯例

- 幂等保证：唯一事务 ID + 状态机 + 乐观锁
- 对账体系：实时 + 分钟级 + 小时级 + 日级
- 亿级策略：异步补偿 + 批量 + 分片 + 指数退避
- 分片补偿：时间分片 + Key 分片 + 优先级分片

## 六、核心带走

- **核心一句话**：分布式事务补偿 = 幂等设计 + 资损对账 + 分片补偿
- **幂等保证**：唯一事务 ID + 状态机 + 乐观锁
- **对账体系**：实时 + 分钟级 + 小时级 + 日级
- **亿级策略**：异步补偿 + 批量 + 分片 + 指数退避
- **哪里会坏**：补偿非幂等、对账遗漏、超时未补偿
