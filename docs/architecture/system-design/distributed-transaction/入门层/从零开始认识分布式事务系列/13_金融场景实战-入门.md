# 金融场景实战

> 跨行转账 / 退款补偿 / 对账闭环——三极谱系在资金链路的收束应用。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 跨行转账的一致性设计

- 场景：本行扣款 + 他行入账（跨机构，无法 2PC）
- 方案：本行记账（账务系统强一致）+ 出金指令（Saga/消息）+ 他行结果回执 + 差错处理
- 在途资金与挂账科目：状态机管理「处理中」资金

## 退款与补偿链路

- 原路退回：依赖原交易链路的可追溯（原单号贯穿）
- 补偿优先级：自动补偿（逆向网关）→ 重试队列 → 人工差错池
- 退款的幂等与重复退款防范（幂等键贯穿全链路，回指分布式理论）

## 对账闭环与审计

- 三方对账：内部账务 vs 渠道账单 vs 银行对账单
- 日切与流水边界：切日时刻的交易归属规则
- 审计要求：全程可追溯（交易流水+状态变更日志），对账差异闭环率是核心指标（衔接专题层「金融资金一致性实战」）
