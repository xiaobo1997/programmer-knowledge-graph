# 分布式事务方案全景

> 强一致 / 柔性 / 最终一致三极全谱系——先建框架再填方案。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 三极谱系总览

- 强一致极：2PC/3PC/XA——锁 + 集中协调，一致性强性能差
- 柔性极：TCC/Saga/AT——预留/补偿/自动回滚，性能好侵入高
- 最终一致极：本地消息表/事务消息/对账——异步追赶，解耦好需兜底

## 各极的代表场景

- 强一致：跨行转账核心记账（钱绝对不能错）
- 柔性：下单扣库存（TCC 预扣）、长流程订单（Saga）
- 最终一致：积分/通知/ES 同步（晚几秒无所谓，对账兜底）

## 按代价定价选方案

- 不一致的业务代价 × 可接受窗口时长 = 选型依据
- 框架只是实现：Seata（AT/TCC/Saga）、RocketMQ（事务消息）都是机制的载体
- 对账是柔性与最终一致的必选项（引出组 4）
