# 最终一致性与对账

> 幂等消费 / 对账补偿兜底——最终一致极的收尾工程。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 最终一致的兑现三件套

- 消息不丢：本地消息表/事务消息保证投递（篇 9-10）
- 消费幂等：去重表/幂等键保证不重复处理（回指分布式理论）
- 对账兜底：漏网之鱼（消息丢/消费失败超限）最终被发现并修复

## 对账体系设计

- 对账维度：总量对账（笔数/金额轧账）+ 明细对账（逐笔匹配）
- 对账频率：准实时（分钟级流式对账）+ 日切全量对账
- 差错处理：长款/短款/金额不符的分类与差错池、人工/自动修复

## 为什么对账是必选项

- 消息会丢（MQ 可用性/磁盘故障）、消费会失败超限、代码有 bug
- 「没有对账的最终一致」= 不知道什么时候会发现算错
- 资金场景的对账是监管要求（回指金融实战篇 13）
