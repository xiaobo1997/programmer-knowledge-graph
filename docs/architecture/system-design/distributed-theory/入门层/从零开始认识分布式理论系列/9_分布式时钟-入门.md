# 分布式时钟

> NTP 局限 / 逻辑时钟 / 向量时钟 / 混合逻辑时钟——没有全局时间怎么办。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 物理时钟不可靠

- 各机器晶体管频率漂移 + NTP 校准（可回拨），时钟无法作为全序依据
- 时钟回拨的实际危害：雪花算法重复发号（回指分布式 ID 系列）
- 「8 点发生的事」在两台机器上无法直接比先后

## 逻辑时钟（Lamport Clock）

- 只保因果序：若 A 因果先于 B，则 clock(A) < clock(B)
- 规则：事件本地 +1；发消息携带时钟；收消息 max(local, msg)+1
- 局限：clock(a) < clock(b) 不能推出 a 因果先于 b（只有单向保证）

## 向量时钟与 HLC

- 向量时钟：每节点维护全向量，能判定因果/并发关系，代价 O(n) 空间
- 混合逻辑时钟（HLC）：物理时间为主 + 逻辑补偿，CockroachDB 等在用
- 工程启示：需要因果判定用向量时钟；只要单调时间戳用 HLC
