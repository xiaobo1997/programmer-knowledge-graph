# 分布式系统是什么与为什么难

> 网络不可靠 / 时钟不可靠 / 8 大谬误 / 部分失败——单机直觉在分布式世界全面失效。对标 DDIA。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 单机到分布式，失去了什么

- 单一进程的可靠假设：函数调用要么成功要么异常
- 分布式后：调用可能超时（结果未知）、节点可能宕机、网络可能分区
- 两大公理：部分失败 + 时钟不可靠——本系列全部理论的起点

## 8 大谬误（分布式新手假设）

- 网络可靠 / 延迟为零 / 带宽无限 / 网络安全 / 拓扑不变 / 管理员存在 / 传输零成本 / 网络同质
- 每条谬误对应一类生产事故：超时重试、延迟长尾、带宽打满等
- 谬误的解法不是消除而是设计时假设它们存在

## 部分失败：分布式独有的困境

- 单机崩溃 = 全部停止，行为确定；分布式部分失败 = 一部分活着一部分挂了
- 核心难题：无法区分「对面挂了」和「网络慢了」（超时判断的两难）
- 引出后续所有理论：一致性模型、共识、幂等都在应对部分失败
