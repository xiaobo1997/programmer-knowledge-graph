# 幂等与去重

> 重试语义 / 幂等键 / 去重表——不可靠网络下的重试安全网。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 为什么重试必然带来重复

- 超时 = 结果未知（可能成功可能失败），只能重试 → 副作用可能执行两次
- 分布式环境下重试不可避免（RPC 重试/消息重投/用户重复点击）
- 幂等定义：同一操作执行多次与一次效果相同

## 幂等实现三件套

- 天然幂等：set 覆盖写 / delete / 状态机条件更新（where status='待支付'）
- 幂等键：客户端生成唯一键，服务端唯一索引拦截重复
- 去重表：消费端记录已处理消息 ID，事务内检查+落表

## 金融场景的幂等要求

- 扣款/退款必须幂等：重复扣款是资金事故（回指分布式事务系列组 4）
- 幂等键设计：订单号+操作类型，生命周期管理（不能永久拦截新业务）
- 与分布式 ID 联动：全局唯一 ID 是幂等键的基础（回指 distributed-id 系列）
