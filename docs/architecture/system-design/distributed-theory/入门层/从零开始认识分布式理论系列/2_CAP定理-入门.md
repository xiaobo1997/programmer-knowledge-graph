# CAP 定理

> 一致性 / 可用性 / 分区容忍，三者取二的真实含义——P 是必选项，选择只在 CA 之间。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 三个性质的定义

- 一致性 Consistency：所有节点同一时刻看到相同数据（线性一致）
- 可用性 Availability：每个请求都能收到（非错误）响应
- 分区容忍 Partition tolerance：网络分区发生时系统仍能运行

## 为什么 P 是必选项

- 分布式系统中网络分区必然发生（交换机、光缆、网卡都会坏）
- P 不选 = 拒绝分布式（回到单机）；真正的选择是分区发生时选 C 还是 A
- CP：拒绝服务保一致（ZooKeeper）；AP：继续服务保最终一致（Eureka）

## CAP 的常见误读

- 误区：三选二是系统级终身选择——实际是逐操作、逐时刻的权衡
- CA 在分布式语境下不存在（无 P 就是单机）
- CAP 之外还有延迟维度（PACELC）：无分区时还要权衡延迟与一致性
