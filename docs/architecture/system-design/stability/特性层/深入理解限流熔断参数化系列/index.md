# 深入理解限流熔断参数化系列

> 限流熔断的算法都懂，参数从哪来？——从单机压测基准、错误预算与容量模型里算出来，这一系列把参数从「拍脑袋」变成「有推导」。

## 一句话摘要

参数化 = 每个阈值都有推导链：限流阈值 ← 单机基准 × 水位系数；熔断阈值 ← 错误预算与误熔断率的权衡；隔离数 ← 线程池容量公式。10w 档静态阈值够用，千万档按容量校准，亿级档动态自适应。

```mermaid
graph LR
    A[单机基准压测<br/>QPS/RT/错误率] --> B[限流阈值<br/>基准 x 水位系数]
    C[错误预算<br/>SLO 推导] --> D[熔断阈值<br/>预算消耗速率]
    E[容量模型<br/>线程池公式] --> F[隔离参数<br/>池大小/信号量]
```

```mermaid
graph TD
    T[量级三档] --> A[10w: 静态阈值 手工校准]
    T --> B[千万: 容量联动 月度校准]
    T --> C[亿级: 动态自适应 + 大促双模]
```

## 演进视角

参数管理的演变：硬编码 → 配置中心 → 动态自适应（自适应限流按 BBR 思想实时推导）——演变方向是「参数的推导链自动化」，人只审边界。
