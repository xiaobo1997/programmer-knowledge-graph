# 雪花算法改进

> Leaf snowflake / UidGenerator——时钟回拨与机器位分配的工业解法。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 机器 ID 分配问题

- 手工分配在千节点集群必然出错（重复机器 ID = 必然重复 ID）
- Leaf 方案：ZooKeeper 顺序节点自动分配 / DB 表分配
- UidGenerator：启动时 DB 分配 workerId，重启累加（WorkNodeId）

## 时钟回拨的工业解法

- Leaf snowflake：回拨小则等待，回拨大则拒绝服务并告警
- UidGenerator：使用历史时间 / 未来时间填充（tailNext 模式），时间位耗尽前告警
- 通用地：监控时钟偏移（NTP 状态）作为前置防御

## 停更现状与自研趋势

- Leaf 6768 stars（2023-07 停更）/ UidGenerator 5560 stars（2023-05 停更）——gh 实测
- 生产趋势：参考思想自研（云厂商内多有自己的发号服务）
- 选型启示：中小规模直接用改造版足够；大规模自研要吃透第 5-6 篇的坑
