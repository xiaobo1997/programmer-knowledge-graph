# 雪花算法原理

> 64 位结构 / 时间戳 + 机器位 + 序列位 / 时钟回拨问题——本地发号之王。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 64 位结构拆解

- 1 bit 符号位（恒 0）+ 41 bit 时间戳（毫秒级 69 年）+ 10 bit 机器 ID（1024 节点）+ 12 bit 序列号（每毫秒 4096 个）
- 单机理论峰值：4096 万/秒；实际受序列位与时钟约束
- 位分配可按业务调整：机房多就拆机器位

## 为什么趋势递增

- 高位是时间戳 → 新 ID 恒大于旧 ID（同一机器内严格、跨机器趋势）
- 对 InnoDB 聚簇索引友好（顺序追加写页）
- ID 含时间信息：可粗略反推生成时间（也是信息泄露点）

## 时钟回拨问题

- 成因：NTP 校准把系统时间往回调 / 时钟漂移
- 危害：回拨期间生成的 ID 会与过去重复（致命）
- 原版应对（抛异常等待）过于朴素——改进方案见第 6 篇；原版 Snowflake 已归档停更（2020-07，gh 实测）
