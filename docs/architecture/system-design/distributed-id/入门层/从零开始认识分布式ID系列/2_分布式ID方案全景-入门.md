# 分布式 ID 方案全景

> UUID / 数据库自增 / 号段 / 雪花 / Redis 五方案一张地图。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 五方案速览

- UUID：本地生成全球唯一，但 128 位无序（索引不友好）
- 数据库自增：单库主键天然有序，分库后失效；步长方案续命
- 号段模式：DB 批量取号段，内存分配（Leaf segment）
- 雪花算法：本地位运算生成，64 位趋势递增
- Redis：INCR 原子自增，依赖 Redis 可用性

## 对比维度

- 唯一性保证方式：中心发号 vs 本地算法
- 有序性：严格递增（号段）/ 趋势递增（雪花）/ 无序（UUID）
- 性能与依赖：本地生成（雪花/UUID）最快；号段/Redis 有外部依赖

## 全景图的用法

- 先定路线（中心 vs 本地），再选具体方案
- 组合使用常见：内部主键雪花 + 对外订单号规则化加密
- 每方案细节见后续各篇
