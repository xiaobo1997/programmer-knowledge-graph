# 多方案对比与选型

> UUID vs 数据库自增 vs 号段 vs 雪花 vs Redis 全面对比 · 决策树 · 维度权衡表

## 系列定位

入门层「分布式 ID 方案全景」列了 5 种方案的名字，本专题做深度对比：
每种方案的适用边界、失效场景、组合使用策略——选型不是「选一个」，是「混用」。

## 篇目规划

| # | 篇目 | 一句话定位 | 优先级 |
|---|---|---|---|
| 1 | 五大方案全面对比 | 唯一性/趋势递增/性能/长度/信息泄露/依赖 五维度量化对比 | 🔴 最高优 |
| 2 | 决策树与选型策略 | 业务四问（量级/有序/长度/安全）→ 决策树 → 混用策略 | 🔴 最高优 |
| 3 | 混用模式 | 内部雪花 + 对外号段 / 订单 ID + 流水号分离 / 多机房独立段 | 高 |
| 4 | 陷阱与反模式 | 自增 ID 外泄 / 机器位重复 / 时钟回拨漏防护 / 长度超限 | 中 |
