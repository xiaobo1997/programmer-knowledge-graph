# 系统设计是什么与三大目标

> 高并发 / 高可用 / 高扩展的定义、度量与冲突——设计始于给目标排优先级。对标凤凰架构。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 三大目标的定义与度量

- 高并发：单位时间处理更多请求（QPS/TPS/RT 分位值）
- 高可用：故障时不中断服务（SLA 99.9%/99.99%，年停机分钟数）
- 高扩展：业务/流量增长时系统能平滑扩容（水平扩展能力）

## 三大目标为什么互斥

- 高并发依赖缓存 → 引入一致性挑战（伤害正确性）
- 高可用依赖冗余 → 引入复制成本与延迟
- 高扩展依赖分片 → 引入跨片事务与运维复杂度
- 设计 = 给目标排优先级 + 明确让步项

## 优先级怎么定

- 按业务代价定价：支付链路可用性优先，营销活动并发优先
- 反例：「三个都要拉满」= 没有设计
- 容量规划是优先级落地的手段（回指篇 9）
