# 缓存架构

> 多级缓存 / 缓存一致性 / 穿透击穿雪崩——高并发第一手段的全景。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 多级缓存体系

- 客户端缓存 → CDN → 网关/本地缓存 → 分布式缓存（Redis）→ DB
- 每一级解决不同距离的访问；层级越多一致性越难
- 本地缓存与分布式缓存的分工（快但难失效 vs 慢但可统一管理）

## 缓存三大经典问题

- 穿透：查不存在的 key → 布隆过滤器/空值缓存
- 击穿：热点 key 过期瞬间打穿 → 互斥锁/逻辑过期
- 雪崩：大量 key 同时过期 → 过期时间加随机/多级兜底

## 缓存一致性

- Cache Aside 模式：读缓存-回源-写库-删缓存
- 先删缓存还是先更新 DB 的时序问题与延迟双删
- 订阅 binlog 的最终一致方案（回指 MySQL 系列；实现细节归 Redis 系列深挖）
