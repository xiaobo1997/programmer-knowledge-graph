# 高可用设计

> 冗余 / 故障转移 / 幂等 / 限流熔断兜底——故障不宕机的四层防线。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 可用性的度量

- SLA 99.9% = 年停机 8.76 小时；99.99% = 52.6 分钟
- 可用性由最脆弱环节决定（木桶）：任何单点都是定时炸弹
- MTBF/MTTR：提升可用性两条路 = 降低故障频率 + 缩短恢复时间

## 冗余与故障转移

- 无单点原则：应用多实例、DB 主从、缓存集群、多机房
- 故障转移：健康检查 + 自动切换（选主/VIP/DNS）
- 主从延迟与切换窗口：切换期间的数据一致性代价

## 兜底三件套

- 限流：超出能力的流量直接拒绝（保住系统）——机制归稳定性工程
- 熔断：下游故障时快速失败不等待——机制归稳定性工程
- 幂等：重试安全的前提（回指分布式理论系列幂等篇）
