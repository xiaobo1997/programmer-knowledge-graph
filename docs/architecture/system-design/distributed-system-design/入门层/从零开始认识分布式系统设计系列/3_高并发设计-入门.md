# 高并发设计

> 扛更多流量的五板斧：缓存 / 异步 / 池化 / 无状态 / 水平扩展。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 五板斧总览

- 缓存：减少对下游的访问（多级缓存，详见篇 4）
- 异步：削峰 + 解耦，把同步链路变短（详见篇 5）
- 池化：连接池/线程池复用资源，降低创建开销
- 无状态：服务不存会话数据，才能水平扩展
- 水平扩展：加机器线性扩容（前提是无状态 + 入口可分流）

## 性能优化的通用方法论

- 先测量再优化：找到真正的瓶颈层（网关/应用/DB）
- 分位值思维：优化 P99 而不是平均值（长尾才是体验杀手）
- 每层的目标：接入层快进快出、业务层无状态、数据层减 IO

## 高并发的边界

- 并发不是无限堆：一致性、成本、复杂度都是约束
- 容量规划定上限（回指篇 9），超出部分靠限流保护（回指稳定性工程）
