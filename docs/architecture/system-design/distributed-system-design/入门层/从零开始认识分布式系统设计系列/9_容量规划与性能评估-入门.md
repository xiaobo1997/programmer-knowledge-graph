# 容量规划与性能评估

> QPS 估算 / 压测 / 容量水位线——把设计落地成数字。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 流量估算方法

- 从业务指标推 QPS：日活 × 人均请求 / 时间分布（二八定律聚焦峰值）
- 峰值系数与增长预留：大促 5-10 倍日常峰值是常态
- 链路放大系数：入口 1 次请求，内部 RPC/DB 访问放大 N 倍

## 压测怎么做

- 单接口基准 → 全链路压测（影子表/流量染色）
- 找系统拐点：吞吐不再涨、RT 开始飙升的并发数 = 容量上限
- 压测环境与数据脱敏（生产压测的流量隔离）

## 水位线与扩容预案

- 容量水位线：一般 60% 预警 / 75% 扩容 / 85% 限流（回指稳定性工程）
- 水位线要按「不可水平扩展的资源」定：DB 连接/单表行数
- 容量评审产出物：估算表 + 瓶颈层结论 + 扩容预案
