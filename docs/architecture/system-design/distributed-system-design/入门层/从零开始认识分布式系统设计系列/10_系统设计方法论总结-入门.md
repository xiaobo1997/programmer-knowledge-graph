# 系统设计方法论总结

> 从需求到方案的完整设计步骤与设计模板——全系列的收束。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 设计六步法

- ① 明确业务目标与约束（量级/一致性要求/SLA/时间）
- ② 估算容量（QPS/存储/带宽，回指篇 9）
- ③ 定接口与数据模型（API 契约/表设计/分片键）
- ④ 画架构：分层 + 组件选型 + 数据流
- ⑤ 逐目标检查：并发/可用/扩展各用什么手段、牺牲什么
- ⑥ 演进路线：第一版做什么、什么指标触发下一步

## 设计评审的检查清单

- 三大目标各自：手段是什么、代价是什么、依据是什么数字
- 单点排查：每一层有没有单点、挂了怎么切
- 兜底排查：限流/熔断/降级/对账各就位没有（回指稳定性工程）

## 本系列与兄弟系列的地图

- 理论地基：分布式理论系列（CAP/一致性/共识）
- 跨服务原子性：分布式事务系列（三极谱系）
- 数据基石：分布式 ID 系列 + MySQL 系列
- 运行期治理：稳定性工程系列（事前/事中/事后）
