# HTTP 语义用对

> 方法语义 / 状态码体系 / 头字段——RFC 9110 的正确打开方式。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 方法语义速查

- GET：安全（不改变状态）+ 幂等 + 可缓存——读操作唯一选择
- POST：非幂等不安全——创建资源/触发动作
- PUT：幂等——全量替换；PATCH：非幂等——部分更新
- DELETE：幂等——删除资源（重复删结果一样）

## 状态码体系（传输层语义）

- 2xx 成功族：200/201（Created）/204（No Content）
- 4xx 客户端错：400 参数/401 未认证/403 无权限/404 不存在/409 冲突/422 语义错/429 限流
- 5xx 服务端错：500/502/503（下游不可用）——4xx 别重试、5xx 可重试，网关与 SDK 都依赖这个语义

## 架空语义的反模式

- 全 200 + 自定义 code：监控失明、网关重试策略失效、SDK 无法统一处理
- 正确分层：状态码表达传输层结果，响应体表达业务细节（RFC 9457 problem details，见篇 6）
