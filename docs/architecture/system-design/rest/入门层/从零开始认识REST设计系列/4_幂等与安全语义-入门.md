# 幂等与安全语义

> 方法幂等矩阵 / 重试安全 / If-Match 乐观锁——接口的并发与重试契约。
>
> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 方法幂等性矩阵

- 安全方法（不改状态）：GET/HEAD/OPTIONS
- 幂等方法（重复执行结果相同）：GET/PUT/DELETE
- 非幂等：POST——「重复下单」的根源

## 重试安全的接口设计

- 超时的本质是结果未知（回指分布式理论）——POST 接口必须考虑重试
- 幂等键方案：客户端生成唯一键（Idempotency-Key 头），服务端唯一索引拦截
- 与分布式幂等的联动：接口层幂等键是全局幂等体系的第一道闸（tips 回指分布式理论幂等篇）

## 条件请求与乐观锁

- ETag + If-Match：读取时拿到 ETag，更新时携带，不匹配返回 412——并发修改互不覆盖
- If-None-Match + 304：缓存校验（回指缓存架构篇）
- 适用场景：配置更新、资料编辑——并发冲突概率低但冲突代价高的资源
