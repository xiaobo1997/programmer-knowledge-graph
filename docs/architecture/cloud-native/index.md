## 文章

### 待建方向

| 方向 | 内容 | 规模 |
|---|---|---|
| 容器化基础 | Docker / 镜像 / 编排 | 待建 |
| Kubernetes | Pod/Service/Deployment/StatefulSet | 待建 |
| Service Mesh | Istio/Envoy/mTLS | 待建 |
| Serverless | FaaS/BaaS/冷启动 | 待建 |
| CI/CD | 流水线/镜像构建/灰度发布 | 待建 |
