# 集群容错系列导读：调用失败之后的处置学

> 入门层 6 篇导读。讲清系列定位、3 组关系、阅读路径、与相邻系列的关系——**不重复入门层定义**。

## 一、这个系列讲什么

集群调用天然会失败：实例挂了、网络抖了、依赖超时了——**失败之后的处置策略**（换节点重试？快速失败？忽略记日志？后台重放？）就是集群容错。本系列讲容错策略族（failover/failfast/failsafe/failback/broadcast）、重试与幂等的绑定关系、以及按场景选策略的方法。边界先划清：**熔断/限流/降级归 stability 子域**（运行期韧性），**超时与重试的参数细节在 RPC 调用视角**（互指 rpc 系列），本系列聚焦「失败处置语义」这一层。

## 五、与相邻系列的关系
