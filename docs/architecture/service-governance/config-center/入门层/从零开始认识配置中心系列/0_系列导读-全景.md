# 配置中心系列导读：配置的集中治理

> 入门层 8 篇导读。讲清系列定位、3 组关系、阅读路径、与相邻系列的关系——**不重复入门层定义**。

## 一、这个系列讲什么

配置散落在各机器的配置文件里：改个超时要发版、环境差异靠人记、敏感配置裸奔——**配置中心把配置变成集中管理、动态推送、可审计的治理资产**。本系列讲配置中心的核心模型（配置项/命名空间/分组/环境）、推送机制（长轮询与推拉）、灰度与回滚、选型与安全。边界先划清：**Nacos/Apollo 组件深挖归 middleware**（互指），**注册中心语义**（服务发现）归 service-discovery（互指），本系列聚焦配置的治理机制。
