# 服务路由系列导读：从均匀分发到定向分发

> 入门层 6 篇导读。讲清系列定位、3 组关系、阅读路径、与相邻系列的关系——**不重复入门层定义**。

## 一、这个系列讲什么

负载均衡把流量「摊匀」，但治理常常要「定向」：灰度版本只给内部员工、多环境流量隔离、故障实例快速切流——**服务路由 = 按规则把流量引到指定实例子集**。本系列讲路由的三种形态（条件路由、标签路由、灰度泳道）与多规则叠加的工程实践。边界先划清：**负载均衡管均匀、路由管定向**（视角型边界互指）；**泳道/灰度与发布策略**的发布侧（互指 graceful-shutdown 与 stability）不重写。
