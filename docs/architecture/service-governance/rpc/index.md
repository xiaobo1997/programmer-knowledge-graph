# ⇄ RPC（远程过程调用）

> 分布式系统最基础的通信机制：让「调用远程服务」像「调用本地方法」一样简单。本层讲 RPC 机制本身（协议 / 序列化 / 服务发现 / 容错），语言无关——Dubbo、gRPC 等具体框架的实现见 [Java 生态 Dubbo 系列](../../../backend/java/ecosystem/dubbo/index)。
