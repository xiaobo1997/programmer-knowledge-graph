# 自定义实现一个 RPC（从零实现）

> 用 Java 从零实现一个最小可用的 RPC：动态代理 + Netty + 序列化 + 注册发现 + 负载均衡。不是为了造轮子，而是为了「掀开框架屏蔽的那层」，彻底理解机制。
>
> **核心观点：** 入门层 13 篇讲清了 RPC 的每个机制，本层把它们串成一个能跑的 demo——实现的过程就是理解机制的过程。
