# 负载均衡系列导读：把流量摊匀的心智模型

> 入门层 7 篇导读。讲清系列定位、3 组关系、阅读路径、与相邻系列的关系——**不重复入门层定义**。

## 一、这个系列讲什么

多实例之后，「请求打给谁」成了治理问题：摊不匀则冷热不均，摊错则会话失效、缓存失效。本系列讲**负载均衡的机制全景**——均衡位置（L4/L7/客户端/服务端）、均衡策略（随机/轮询/一致性哈希/最少活跃）、选型方法——位置与策略各自的取舍逻辑是贯穿全线的权衡主线。边界先划清：**与「服务路由」的分工**——负载均衡回答「均匀分发」（把流量摊开），服务路由回答「定向分发」（把流量引到指定子集，灰度/泳道），两边 tips 互指不重写——这条边界是多轮治理体系演进中沉淀的分工共识。
