# 跨境支付清结算体系

> 清结算是跨境支付的"后半场"——清算 = 算账，结算 = 转账。本专题深入拆解跨境清结算的完整体系。

## 学习路线

```
☐ 1. 跨境清结算概述 — 和国内清结算有什么不同
☐ 2. 卡组织清算规则 — VISA/MC/银联各自的清算周期和规则
☐ 3. 轧差计算原理 — 多币种轧差的数学和工程实现
☐ 4. 换汇与汇率管理 — 实时换汇 vs 批量换汇的深度 trade-off
☐ 5. 结算周期优化 — T+3 能不能压到 T+1
☐ 6. 清结算系统设计 — 清算引擎 + 结算引擎的架构深度
☐ 7. 异常处理与调账 — 长款/短款/差错/争议的完整处理流程
☐ 8. 多币种清结算 — 多币种混合清算的复杂度
```
