# 多币种账户体系：从模型到状态机的设计原理

> **一句话定义**：跨境收单的账户体系 = 每个商户有多个币种子账户 + 一个分润账户 + 一个保证金账户。核心挑战不是存钱，而是汇率波动时怎么记账和怎么对账。

---

## 1. 账户模型

```mermaid
erDiagram
    商户主账户 ||--|{ 币种子账户 : "1:N"
    币种子账户 ||--o{ 交易流水 : "进出"
    商户主账户 ||--|| 保证金账户 : "冻结资金"
    商户主账户 ||--|| 分润账户 : "待分资金"
    交易流水 ||--o{ 分润明细 : "分账"
    币种子账户 ||--o{ 换汇记录 : "换汇"
    
    商户主账户 {
        string 商户号 PK
        decimal 总余额_CNY
        string 状态
        datetime 创建时间
    }
    
    币种子账户 {
        string 账户号 PK
        string 商户号 FK
        string 币种
        decimal 余额
        decimal 冻结金额
        decimal 可用余额
    }
    
    交易流水 {
        string 流水号 PK
        string 账户号 FK
        string 交易类型
        decimal 原币金额
        decimal 人民币金额
        decimal 汇率
    }
    
    保证金账户 {
        string 商户号 FK
        decimal 保证金余额
        decimal 冻结金额
        string 保证金比例
    }
```

## 2. 账户状态机

```mermaid
stateDiagram-v2
    [*] --> 正常
    正常 --> 冻结: 风控/保证金不足
    正常 --> 限制提现: 风险商户
    冻结 --> 正常: 解除风控
    限制提现 --> 正常: 解除限制
    冻结 --> 销户中: 商户申请注销
    限制提现 --> 销户中: 商户申请注销
    销户中 --> 已销户: 余额清零+在途交易完成
    已销户 --> [*]
```

---

## 3. 换汇策略

| 策略 | 做法 | 优势 | 劣势 |
|---|---|---|---|
| 实时换汇 | 每笔交易立即换汇 | 锁定汇率、无汇损风险 | 高频交易成本高 |
| 批量换汇 | T+1 汇总后统一换 | 降低换汇成本 | 汇率波动风险 |
| 原币结算 | 不换汇，原币打给商户 | 商户自己换汇 | 需要商户有外币账户 |

---

## 4. 一句话总结

> **多币种账户 = 每个币种一个子账户 + 实时冻结 + 状态机控制。核心 trade-off 是换汇时机：实时锁定汇率 vs 批量降低成本。**
