# 跨境支付收单 — 知识大纲

> **目标**：用技术人的视角，把跨境支付收单讲成一套可自学的课程。18 篇文章系统覆盖参与方、交易、模式、架构、通道、对账、账户、风控、实战、全局设计。

---

## 学习路线图

```
✅ 第1篇 概述-10分钟入门
      国内 vs 跨境、7站旅程、卡组织、3DS、DCC、Chargeback
      │
✅ 第2篇 参与方全景-9类角色拆解
      发卡行/卡组织/收单行/收单机构/商户/通道、利益分配、风险归属
      │
✅ 第3篇 外卡支付链路-从授权到结算
      授权/捕获/结算三阶段、3DS分支、chargeback全流程
      │
✅ 第4篇 业务模式-费率与分润深度
      聚合vs直连、本地vs跨境、费率结构、分润模型
      │
✅ 第5篇 收单系统架构-模块与部署
      功能架构、系统拓扑、技术栈、部署方案
      │
✅ 第6篇 通道管理与路由-深度
      通道分类/属性/生命周期/路由策略/健康度
      │
✅ 第7篇 跨境对账与结算-架构设计
      三方对账、结算周期、换汇流程、差异处理
      │
✅ 第8篇 多币种账户体系-设计原理
      账户模型、分润账户、汇率损益、状态机
      │
✅ 第9篇 风控与合规-跨境监管框架
      3DS、风控规则、拒付率、AML/KYC、制裁名单
      │
✅ 第10篇 端到端实战-境外卡全链路
      一个真实场景从头走到尾（下单→授权→清算→结算→拒付）
      │
✅ 第11篇 全局架构设计-跨境收单系统全景
      4+1视图、技术栈全景、trade-off汇总、从零搭建决策清单
```

---

## 共性与特性

| 维度 | 共性（通用支付知识） | 特性（跨境独有） |
|---|---|---|
| 参与方 | 用户、商户、收单机构 | 卡组织、发卡行在境外、收单行 |
| 交易流程 | 下单 → 支付 → 回调 | 汇率报价、3DS 认证、多币种清算 |
| 资金流 | 用户→收单→商户 | 发卡行→卡组织→收单行→收单机构→换汇→商户 |
| 风险 | 盗刷、欺诈 | 拒付（chargeback）、汇率波动 |
| 合规 | 央行监管 | 外管申报、反洗钱、制裁名单 |
| 技术 | 支付网关、收银台 | 多币种、多时区、多卡组织协议适配 |
