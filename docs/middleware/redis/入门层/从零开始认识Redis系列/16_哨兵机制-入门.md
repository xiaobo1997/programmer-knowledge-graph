# 哨兵机制

> 监控/选主/故障转移 + 脑裂与 quorum 直觉——自动故障转移的守护者。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 背景：主挂了谁来管

- 手动切换的不可接受
- 哨兵的定位：高可用管家

### 2. 核心：哨兵三职能

- 监控/通知/自动故障转移
- 主观下线 vs 客观下线

### 3. 机制：选主与脑裂

- quorum 与 majority
- 脑裂的数据丢失窗口

- 奇数节点与 quorum 配置
- 客户端感知主从切换
