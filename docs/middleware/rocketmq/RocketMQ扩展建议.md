## 缺口分析

### A 线（微观机制深挖）缺口

- 整合层 代码接入：只有 SpringBoot 接入，缺多语言客户端 / 高级用法
- 整合层 场景实践：只有消费线程池选型，缺生产者端场景 / 事务消息实践

### B 线（宏观架构决策）缺口

- 选型对比：RocketMQ vs Kafka vs Pulsar 决策树缺失
- 混合云架构：刚补完 1 篇，需补充 2_跨云容灾实战-深度.md
- 背压与流控：刚补完 1 篇，需补充 2_限流算法对比-深度.md

### C 线（实战 Demo）缺口

- 从零实现 RocketMQ 生产者（同步/异步/单向发送 Demo）
- 从零实现 RocketMQ 消费者（Push/Pull/Pop 消费 Demo）
- 事务消息从零实现（本地消息表 + 事务消息 Demo）
