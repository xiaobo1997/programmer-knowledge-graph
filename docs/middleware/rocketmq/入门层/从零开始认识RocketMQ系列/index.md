# 从零开始认识 RocketMQ 系列

> 这是 RocketMQ 学习体系的 **L1 入门层**——「概念扫盲 + 第一步使用」，11 篇全景讲透 RocketMQ 是什么、怎么用、怎么选。
>
> **核心观点：** 入门层让你从「消息中间件是什么」到「RocketMQ 怎么用」，10 分钟建立 RocketMQ 全景认知，再看特性层深挖原理。

- ✅ **每篇一个核心模块**（概念 → 生态 → 架构 → 生产/消费 → 存储/路由 → 选型）
- ✅ **全景视角**（-全景 后缀，一篇 2000-4000 字，不深入源码）
- ✅ **承接入门 → 导向特性层**（学完能用，再看特性层看穿源码）
- ✅ **不重复特性层**（源码级细节留给 L2，这里只讲是什么 + 怎么用）
