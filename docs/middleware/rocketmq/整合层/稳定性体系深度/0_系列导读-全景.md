# RocketMQ 稳定性体系深度：4 维稳定性 + 7 维监控 + 混沌工程

> 一句话摘要：**RocketMQ 稳定性体系 = 4 维稳定性（可用性 / 可靠性 / 可观测性 / 韧性）+ 7 维监控指标 + 6 类混沌工程演练**。本专题定位 L4 整合层，跨 L2 特性层 + L3 专题层，整合"散落的稳定性实践"为"系统化工程"。

> 本专题定位：**L4 整合层 · 跨特性稳定性综合 · 3 篇 deep-dive**（不替代 L2/L3 专题）。L4 是 RocketMQ 学习体系的最高层——把单点稳定性整合为全局视图。

---

## 为什么 L4 整合层

RocketMQ 稳定性实践在仓库中**散落在多处**：
- L2 特性层篇 6-9：消费 / 主从 / 存储 / 集群的稳定性机制
- L3 事务消息篇 5：事务消息专属监控告警
- L3 生产配置深度：消费线程配置
- L3 Topic 隔离深度：业务域隔离

但**真正生产中，SRE 视角需要的是全局稳定性图**——不是"事务消息怎么监控"，而是"整个 RocketMQ 系统怎么稳定运行"。

**这就是 L4 的核心价值**：

```
L1 入门层：什么是 RocketMQ
L2 特性层：单特性怎么稳定
L3 专题层：单场景怎么稳定
L4 整合层 ← 全局怎么稳定
```
