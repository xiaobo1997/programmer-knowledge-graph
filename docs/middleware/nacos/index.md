# 中间件 · Nacos 注册与配置中心

> 微服务一多，两件事立刻变难：「服务在哪」（注册发现）和「配置怎么改」（动态配置）。Nacos 把这两件事做在了一起。学它最容易犯的错是把「机制」和「组件」混在一起：服务发现为什么需要注册中心、配置中心的推送模型有哪些，这类**跨实现机制**在架构域的服务治理系列讲；本系列专注 **Nacos 这个组件本身**——它的数据模型、AP/CP 双协议、长连接演进和生产落地。

## 一、这个系列怎么读

按 4 层架构组织，每层可独立进入：

```
L1 入门层：Nacos 是什么 + 两大模块 + 接入（机制概念 tips 点到组件）
L2 特性层：核心实现深挖（注册发现 / 配置中心 / Distro 与 Raft）

```
