# 集群规划与容量

> broker 数 / 分区数 / 副本因子 / 磁盘带宽估算——从「能跑」到「规划过」。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 背景：容量问题都是设计问题

- 吞吐/保留时长/副本放大三输入
- 分区数×副本=总存储的直觉

### 2. 核心：关键容量公式与估算

- 单分区吞吐假设 / 总分区数限制
- 磁盘容量 = 日吞吐×保留天数×副本

### 3. 机制：broker 与机架布局

- broker 数量与分区分布
- 机架感知副本放置

### 4. 实践：容量规划模板

- 小/中/大规模集群的典型配置
- 压测验证（专题 2 衔接）
