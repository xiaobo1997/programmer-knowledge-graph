# 深入理解存储引擎系列（原理深挖）

> segment 布局 / 稀疏索引 / 页缓存与零拷贝 / 压缩与批量格式——磁盘与内存的每一字节怎么组织。
>
> **核心观点：** Kafka 的快不是魔法：追加写 + 页缓存 + 零拷贝三板斧，外加稀疏索引与批量格式——读代码后吞吐直觉会变得可计算。
