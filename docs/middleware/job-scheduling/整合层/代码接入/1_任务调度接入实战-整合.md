# 任务调度接入实战

> 接入不是「配个 cron」——从代码到平台，每一步都有坑。

## 一句话摘要

> 接入 = 框架集成 + 配置 + 测试 + 监控——四步缺一不可。

## xxl-job 接入

|| 步骤 | 内容 |
|---|---|---|
| 1 | 引入依赖 | xxl-job-core |
| 2 | 配置执行器 | 地址 + Token |
| 3 | 编写 JobHandler | @JobHandler |
| 4 | 配置 cron | 触发规则 |
| 5 | 测试 | 控制台触发 |
| 6 | 监控 | 日志 + 告警 |

## PowerJob 接入

|| 步骤 | 内容 |
|---|---|---|
| 1 | 引入依赖 | powerjob-worker |
| 2 | 配置 Server 地址 | 集群地址 |
| 3 | 编写 Processor | @Processor |
| 4 | 配置 cron | 触发规则 |
| 5 | 测试 | 控制台触发 |
| 6 | 监控 | 日志 + 告警 |

## ElasticJob 接入

|| 步骤 | 内容 |
|---|---|---|
| 1 | 引入依赖 | elasticjob-lite |
| 2 | 配置 ZK 地址 | 集群地址 |
| 3 | 编写 Job | SimpleJob / DataflowJob |
| 4 | 配置 cron | 触发规则 |
| 5 | 测试 | 控制台触发 |
| 6 | 监控 | Tracing + 告警 |

## 生产检查项

|| 检查项 | 标准 |
|---|---|---|
| 幂等 | 任务 ID + 去重 | 必须 |
| 超时 | 执行超时设置 | 必须 |
| 重试 | 失败重试策略 | 必须 |
| 告警 | 失败告警 | 必须 |
| 监控 | 日志聚合 | 推荐 |

## 常见陷阱

- ❌ 不设超时 = 任务hang住
- ❌ 不配重试 = 失败不处理
- ❌ 不监控 = 故障发现晚

- 千万级：调大线程池 + 分片
