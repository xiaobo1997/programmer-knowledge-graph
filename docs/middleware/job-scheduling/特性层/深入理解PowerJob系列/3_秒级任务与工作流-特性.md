# PowerJob 秒级任务与工作流

> 秒级任务 = 1s 内触发，工作流 = 多步骤编排——PowerJob 的两大杀手锏。

## 一句话摘要

> 秒级任务解决「准点触发」，工作流解决「多步骤编排」——两者让调度从「定时」到「智能」。

## 秒级任务

|| 维度 | 说明 |
|---|---|---|
| 触发精度 | 1s | 秒级 |
| 适用 | 实时计算 / 监控告警 | - |
| 代价 | 资源占用高 | - |

## 工作流

|| 维度 | 说明 |
|---|---|---|
| DAG | 有向无环图 | 多步骤依赖 |
| 并行 | 多个分支同时 | 提速 |
| 串行 | 依次执行 | 顺序依赖 |
| 条件 | 分支判断 | 动态路由 |

## 工作流示例

```
数据准备 → 并行处理 A/B → 合并 → 写入 → 通知
```

## 生产陷阱

- ❌ 秒级任务不限流 = DB 打满
- ❌ 工作流不设超时 = 无限等待
- ❌ 工作流不持久化 = 宕机后丢失

## 量级参考

- 10w 档：不用秒级，不用工作流
- 千万级：秒级任务 + 简单工作流
- 亿级：秒级 + 复杂 DAG 工作流
