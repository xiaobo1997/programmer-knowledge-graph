# DelayQueue 局限与时间轮原理

> DelayQueue 是 Java 内置的延迟队列——简单但有局限，时间轮是工业级方案。

## 一句话摘要

> DelayQueue = 简单延迟队列（万级），时间轮 = 工业级调度（百万级）——量级不同选不同。

## DelayQueue

|| 维度 | 说明 |
|---|---|---|
| 原理 | 优先级队列 + 延迟检查 | - |
| 精度 | 毫秒级 | - |
| 容量 | 万级 | 内存限制 |
| 适用 | 低频延迟任务 | - |

## 时间轮

|| 维度 | 说明 |
|---|---|---|
| 原理 | 环形数组 + 指针 | - |
| 精度 | 毫秒/秒级 | 可配 |
| 容量 | 百万级 | 固定槽位 |
| 适用 | 高频定时任务 | - |

## 单层 vs 多层时间轮

|| 类型 | 精度 | 适用 |
|---|---|---|---|
| 单层 | 秒级 | 短期定时 |
| 多层 | 毫秒级 | 长期定时 |

## 量级对比

|| 方案 | 量级 |
|---|---|---|
| DelayQueue | 万级 | 低频 |
| 单层时间轮 | 十万级 | 中频 |
| 多层时间轮 | 百万级 | 高频 |

## 生产陷阱

- ❌ DelayQueue 当任务队列用——内存溢出
- ❌ 时间轮槽位不够 = 任务丢失
- ❌ 时间轮不调推进 = 任务延迟
