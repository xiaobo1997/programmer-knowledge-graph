# xxl-job 幂等与阻塞策略

> 幂等 = 重复执行不副作用，阻塞 = 上个任务没结束下个触发怎么办——两者决定任务可靠性。

## 一句话摘要

> 幂等是「重复执行不出错」，阻塞是「上一个没结束下一个怎么办」——生产环境两者必面对。

## 幂等策略

|| 策略 | 说明 | 适用 |
|---|---|---|---|
| 数据库唯一索引 | 天然去重 | 数据写入 |
| Redis set | 去重 | 分布式场景 |
| 状态机 | 状态驱动 | 多步骤任务 |
| 幂等令牌 | 请求带令牌 | API 场景 |

## 阻塞策略

|| 策略 | 说明 |
|---|---|---|
| 单机串行 | 一个执行器一次只处理一个任务 | 安全但慢 |
| 丢弃后续 | 新触发丢弃 | 高优先任务 |
| 并行执行 | 同时执行多个 | 快速但可能冲突 |

## 组合策略

|| 场景 | 幂等 | 阻塞 |
|---|---|---|---|
| 数据写入 | DB 唯一索引 | 单机串行 |
| API 调用 | 幂等令牌 | 并行 |
| 批量处理 | 状态机 | 丢弃后续 |

## 生产陷阱

- ❌ 不幂等 + 并行 = 数据重复
- ❌ 不处理阻塞 = 任务堆积
- ❌ 幂等令牌不校验 = 形同虚设

## 量级参考

- 10w 档：DB 唯一索引 + 单机串行
- 千万级：Redis 去重 + 并行
- 亿级：状态机 + 丢弃后续
