# xxl-job 日志链路与告警

> 日志链路 = 追踪任务从触发到结束的完整路径——没有链路追踪，任务失败就是黑盒。

## 一句话摘要

> 日志链路 = 任务 ID + 执行器 + 开始/结束 + 结果 + 异常——五要素齐备才能定位。

## 日志五要素

|| 要素 | 说明 |
|---|---|---|
| 任务 ID | 唯一标识 | 哪台机器跑的 |
| 执行器 | 执行器地址 | 哪个节点 |
| 开始时间 | 触发时间 | 何时开始 |
| 结束时间 | 完成时间 | 何时结束 |
| 结果 | 成功/失败 | 执行结果 |

## 告警策略

|| 触发条件 | 动作 |
|---|---|---|
| 失败 | 任务执行失败 | 告警 + 重试 |
| 超时 | 超过设定时间 | 告警 + 终止 |
| 堆积 | 排队 > 阈值 | 告警 + 扩容 |
| 离线 | 执行器离线 | 告警 |

## 链路追踪

- 日志聚合：ELK / Loki
- 链路 ID：每个任务生成唯一链路 ID
- 分布式追踪：跨执行器追踪

## 生产陷阱

- ❌ 日志不包含任务 ID——失败无法定位
- ❌ 告警只发不处理——告警疲劳
- ❌ 超时不终止——任务堆积

## 量级参考

- 10w 档：日志 + 告警够用
- 千万级：链路追踪 + 聚合
- 亿级：全链路 + 自动分析
