# xxl-job 分片路由与故障转移

> 分片路由 = 任务数据怎么切到不同机器，故障转移 = 机器挂了任务怎么转移。

## 一句话摘要

> 分片路由解决「数据怎么分」，故障转移解决「机器挂了怎么办」——两者正交但常一起用。

## 分片路由

|| 模式 | 说明 |
|---|---|---|
| 自动分片 | 按数据量均分 | 数据均匀 |
| 手动分片 | 指定分片索引 | 特殊场景 |
| 一致性哈希 | 数据映射到节点 | 扩容影响小 |

## 故障转移

|| 策略 | 说明 |
|---|---|---|
| 失败转移 | 失败后重试其他节点 | 高可用 |
| 繁忙转移 | 节点忙时转其他节点 | 防过载 |
| 丢弃 | 失败不重试 | 低优先 |

## 分片 + 故障转移组合

|| 场景 | 分片 | 故障转移 |
|---|---|---|---|
| 数据均匀 | 自动分片 | 失败转移 |
| 数据倾斜 | 手动分片 | 繁忙转移 |
| 扩容频繁 | 一致性哈希 | 失败转移 |

## 生产陷阱

- ❌ 分片不均 + 故障转移 = 热点叠加
- ❌ 故障转移不持久化——宕机恢复后状态错乱
- ❌ 分片数 > 机器数 = 部分机器多任务

## 量级参考

- 10w 档：自动分片 + 失败转移
- 千万级：手动分片 + 繁忙转移
- 亿级：一致性哈希 + 自动故障转移
