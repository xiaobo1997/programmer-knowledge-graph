# 任务调度生产实战：重复执行与幂等防护

> 重复执行是调度系统最常见的事故——幂等不是可选项，是必选项。

## 一句话摘要

> 重复执行 = 网络超时 + 重试 + 并发触发——幂等防护 = 去重 + 状态机 + 唯一约束。

## 重复执行场景

|| 场景 | 原因 | 频率 |
|---|---|---|---|
| 网络超时 | 重试 | 高 |
| 并发触发 | 多个触发器 | 中 |
| 宕机恢复 | 重跑 | 低 |
| 手动重跑 | 运维操作 | 低 |

## 幂等方案

|| 方案 | 原理 | 复杂度 |
|---|---|---|
| DB 唯一索引 | 天然去重 | 低 |
| Redis set | 去重 | 中 |
| 状态机 | 状态驱动 | 高 |
| 幂等令牌 | 令牌校验 | 中 |

## 生产事故案例

|| 事故 | 原因 | 影响 |
|---|---|---|
| 对账重复 | 网络超时重试 | 多笔对账 |
| 扣款重复 | 并发触发 | 资金损失 |
| 数据重复 | 宕机恢复重跑 | 数据脏 |

## 量级参考

- 10w 档：DB 唯一索引 + 状态机
- 千万级：Redis 去重 + 状态机
- 亿级：幂等令牌 + 状态机 + 审计
