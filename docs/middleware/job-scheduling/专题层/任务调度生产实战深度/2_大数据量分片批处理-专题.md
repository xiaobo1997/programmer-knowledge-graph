# 任务调度生产实战：大数据量分片批处理

> 百万级数据分片——不分片 = 单机超时，分片不均 = 长尾拖垮 SLA。

## 一句话摘要

> 大数据量分片 = 数据划分 + 路由 + 合并——分片不均比不分片更糟。

## 分片策略

|| 策略 | 原理 | 适用 |
|---|---|---|---|
| 范围分片 | 按数据范围 | 时间范围 |
| 哈希分片 | 哈希取模 | 无规律 |
| 一致性哈希 | 环形映射 | 动态扩缩 |
| 手动分片 | 指定分片 | 特殊场景 |

## 批处理优化

|| 优化 | 说明 |
|---|---|---|
| 批量提交 | 减少 DB 交互 | 100-1000 条/批 |
| 异步处理 | 不阻塞主线程 | IO 密集 |
| 流式处理 | 内存友好 | 超大数据 |

## 长尾治理

|| 问题 | 解法 |
|---|---|---|
| 数据倾斜 | 预处理打散 | - |
| 慢任务 | 超时拆分 | - |
| 热点节点 | 迁移任务 | - |

## 生产事故案例

|| 事故 | 原因 | 影响 |
|---|---|---|
| 分片不均 | 哈希碰撞 | 部分机器超时 |
| 内存溢出 | 一次性加载 | OOM |
| 连接池满 | 并发过高 | 连接超时 |

## 量级参考

- 10w 档：不分片够用
- 千万级：范围分片 + 批量提交
- 亿级：一致性哈希 + 流式处理
