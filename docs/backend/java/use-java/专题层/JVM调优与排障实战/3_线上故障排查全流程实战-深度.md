# 线上故障排查全流程实战

> 线程死锁、CPU 飙高、频繁 Full GC 三个高频线上故障的完整排查复盘：现象→取证→定位→修复。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 背景：三类高频故障的共同套路
- 报警现象如何翻译成排查方向
- jstack/jstat/jmap/Arthas 工具箱串联

### 2. 案例一：线程死锁
- jstack 死锁检测输出解读
- 锁顺序与资源竞争根因
- 修复与预防（锁排序/超时锁）

### 3. 案例二：CPU 飙高
- top + jstack 定位线程与代码行
- 自旋/死循环/GC 线程的区分
- 火焰图快速定位热路径

### 4. 案例三：频繁 Full GC
- jstat 观察 GC 频率与晋升
- 内存泄漏 vs 配置不当的判别
- 与案例一（OOM）的衔接

### 5. 复盘模板
- 时间线 / 根因 / 影响面 / 改进项
- 故障演练与预案沉淀

### 6. 速记卡
- 三类故障排查速查表收束
