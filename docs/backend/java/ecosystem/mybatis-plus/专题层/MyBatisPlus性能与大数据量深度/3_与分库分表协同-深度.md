# 与分库分表协同：MP + 分片中间件

> 单表撑不住后分库分表，MP 还好使吗：SQL 拦截层叠加、分片键纪律、跨分片分页正确性、主键策略。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 问题域全景
- 分片后 BaseMapper 还能用吗
### 2. 机制层：两个 SQL 拦截层叠加
- MP 生成 SQL → 中间件路由改写，职责边界
### 3. 分片键纪律
- Wrapper 必须带分片键，否则全路由
### 4. 跨分片分页正确性
- 归并策略 vs 流式、深翻页代价更大、keyset 出路
### 5. 主键与唯一性
- MP ASSIGN_ID 雪花 vs 中间件主键，别双写
### 6. 何时才需要分库分表
- 索引/归档/读写分离演进判断
### 7. 落地复盘（脱敏）
- 按客户分片实践；跨分片分页偶发漏/重排查
