# 大分页深翻页优化体系

> LIMIT 1000000, 20 为什么越来越慢：offset 代价模型 + 覆盖索引/keyset/业务收敛三路选型。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 问题域全景
- 深翻页本质：扫 offset+size 再丢 offset
### 2. 代价模型
- 索引回表放大，加索引解决不了深翻页
### 3. 三条优化路对比
- 覆盖索引延迟关联 / keyset 游标 / 时间范围收敛选型表
### 4. 代码范式
- MP keyset 落地与 Page 取舍、total 矛盾
### 5. 分页插件本身的坑
- count 代价、maxLimit
### 6. 落地复盘（脱敏）
- 千万级流水列表改造实录
### 7. 反模式清单
- 全站 keyset、游标还 count
