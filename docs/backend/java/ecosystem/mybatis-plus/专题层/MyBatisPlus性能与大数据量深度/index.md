# MyBatis-Plus 性能与大数据量深度（专题）

> MyBatis-Plus 专题层第二个组合拳：数据量上来之后，MP 写的 SQL 还扛不扛得住——深翻页、批量写、分库分表三场硬仗。
>
> **核心观点：** MP 让单表 CRUD 简单，但大数据量场景的瓶颈不在「会不会用 API」，而在「对 SQL 执行代价有没有数」——分页要 keyset、批量要合并、分片要守分片键。
