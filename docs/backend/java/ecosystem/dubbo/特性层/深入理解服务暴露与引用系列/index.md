# 深入理解服务暴露与引用系列（源码级深挖）

> 服务暴露（export）和服务引用（refer）是 Dubbo 的「服务生命周期」核心——Provider 怎么上线服务、Consumer 怎么拿到调用代理，全在这两条链路里。
