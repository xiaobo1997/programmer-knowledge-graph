# Dubbo 监控与可观测（横向组合拳）

> 指标、日志、链路追踪——服务上线后「怎么看见它跑得好不好」是生产运维的基本功。本专题把 Dubbo 的可观测能力串起来。
>
> **核心观点：** 一次 RPC 调用从指标（metrics）、日志（log）、链路（trace）三个维度看清，是「服务可观测」的完整落地。

| L1 入门层 | 概念扫盲 + 会用 | [入门 12（服务治理）](../../入门层/从零开始认识Dubbo系列/0_系列导读-全景) |
| L2 特性层 | 单点纵向深挖 | [过滤器链](../../特性层/深入理解过滤器链系列/index)（Filter 埋点） |
| **L3 专题层** ✅ | 多点横向组合拳 | **本专题（篇目待定稿）** |

## 二、规划方向（篇目待定稿）

| 方向 | 覆盖内容 |
|---|---|
| Admin 控制台 | 服务治理可视化 / 调用关系 |
| 指标监控 | QPS/RT/错误率 / Prometheus 接入 |
| 链路追踪 | TraceId 透传 / 全链路接入 |
| 可观测落地 | 指标 + 日志 + 链路三件套整合 |

**主线：** Admin → 指标 → 链路 → 可观测落地
