# 依赖注入详解

> @Autowired 与 @Resource 的差异、三种注入方式的取舍、注入失败怎么排查——依赖注入的完整决策树。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 背景：依赖为什么不能自己 new

- 依赖倒置原则的工程价值
- 可测试性与可替换性

### 2. 核心：注入方式三种对比

- 构造器注入：不可变 + 必填依赖
- 字段注入：简洁但隐藏依赖
- setter 注入：可选依赖场景

### 3. 机制：@Autowired vs @Resource

- 类型优先 vs 名称优先的查找规则
- @Qualifier / @Primary 多实现选择
- required=false 与 Optional 注入

### 4. 实践：注入失败排查手册

- NoSuchBeanDefinition / NoUniqueBeanDefinition 解读
- 循环依赖报错与规避预览
- 为什么团队规范常推构造器注入
