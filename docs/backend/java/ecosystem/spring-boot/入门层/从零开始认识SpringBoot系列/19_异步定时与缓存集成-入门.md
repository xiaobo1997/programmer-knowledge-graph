# 异步、定时与缓存集成

> @Async 线程池、@Scheduled 定时任务、@Cacheable 缓存抽象——三个高频注解一次集成，衔接 Java 线程池与 Redis。

> 本文为系列规划大纲页：篇目结构已定，正文按下方骨架落盘。

## 规划大纲

### 1. 背景：三类基础能力

- 异步化/定时调度/缓存是后端标配
- 与 Java 语言系列线程池、Redis 系列的衔接点

### 2. 核心：@Async 与线程池

- 启用与线程池配置（TaskExecutor）
- @Async 失效场景（自调用/返回值）
- 线程池隔离与监控

### 3. 机制：@Scheduled 定时任务

- cron/固定频率/延迟执行
- 单机默认串行与多实例重复执行问题
- 分布式调度（xxl-job 等）衔接

### 4. 实践：@Cacheable 缓存抽象

- 注解驱动的缓存读写
- 缓存失效/穿透与 Redis 落地
- CacheManager 选型与序列化问题
