# Python 实战

> Python 工程实践 + 语言特性 + AI/Agent 生态学习。

## 子主题

- （待建：Python 基础 → 工程化 → AI/Agent 应用）

## 生态定位

### 在哪里

- 后端服务（FastAPI / Django / Flask）
- 数据科学 & AI/ML 绝对主流（PyTorch / LangChain / Agent 生态）
- 脚本自动化 / DevOps 工具链

### 现在怎么样

- Python 3.12 / 3.13（当前稳定版）
- AI/Agent 时代生态第一语言（openai-python 31k star vs openai-java 1.5k）
- 类型标注（PEP 484）+ 静态检查（mypy / pyright）补齐工程短板

### 能干什么

| 场景 | Python 适合度 |
|---|---|
| 后端微服务 | ⭐⭐⭐（FastAPI 高性能异步）|
| 数据科学 / AI/ML | ⭐⭐⭐⭐⭐（绝对主流）|
| Agent / LLM 应用 | ⭐⭐⭐⭐⭐（生态最全）|
| 脚本自动化 | ⭐⭐⭐⭐⭐ |
| 性能敏感系统 | ⭐⭐（可 C/Rust 扩展）|

### 怎么配合

- FastAPI（现代后端）+ Pydantic（校验）
- PyTorch / LangChain（AI/Agent）
- uv / poetry（依赖管理）
- mypy / ruff（工程质量）

### 类似什么

| 方案 | 类型 | 优势 | 劣势 |
|---|---|---|---|
| Python | 解释型 | 生态最大（AI 领域）/ 上手快 | 性能 / 类型弱 |
| Go | 编译型 | 部署简单 / 并发强 | AI 生态弱 |
| Java | 编译型 | 工程化成熟 | AI 生态弱 |

### 怎么演进

- Python 2 → 3 → 3.8+（async）→ 3.12+（类型完善）
- 工程化补齐：类型标注 → 静态检查 → 包管理（uv）→ 测试
- AI 方向：Jupyter（探索）→ 工程化（Agent 框架 / MCP）

## 一句话总结

> Python 是「AI/Agent 时代的第一语言」——生态绝对主流，工程化短板正在补齐（类型 + 工具链）。
