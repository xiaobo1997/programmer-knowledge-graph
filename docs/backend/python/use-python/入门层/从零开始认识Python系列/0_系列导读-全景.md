# 从零开始认识 Python 系列导读

> 这个系列回答一个问题：**一个会编程或不会编程的人，怎么从零建立 Python 的完整心智模型**——15 篇从「它是什么」走到「能写正经程序」，每一篇都讲机制而不止语法。

## 一句话摘要

Python 是一门**解释执行的动态类型语言**，以「可读性优先」的设计哲学统治了数据科学与 AI 工程（量级演进：从脚本语言到 AI 时代的第一语言）。系列沿「类型 → 容器 → 函数 → 对象 → 模块化 → 异常 → IO → 生态」的主线铺开，每篇带「机制为什么这样设计 + 常见误区 + 与邻居语言对比」三个固定视角。

```mermaid
graph LR
    A[起步 1-4<br/>是什么与数据] --> B[容器与逻辑 5-7]
    B --> C[抽象 8-10<br/>函数/类/协议]
    C --> D[工程 11-15<br/>模块/异常/IO/测试]
```

## 系列地图（15 篇四段）

| 段 | 回答的问题 | 篇目 |
|---|---|---|
| 起步 | Python 是什么、怎么跑起来、数据长什么样 | 1 是什么 / 2 安装运行 / 3 变量类型 / 4 字符串编码 |
| 容器与逻辑 | 列表/字典/控制流——程序的组织材料 | 5 列表元组 / 6 字典集合 / 7 控制流推导式 |
| 抽象 | 函数/类/协议——复用的三层机制 | 8 函数与作用域 / 9 类与对象 / 10 魔法方法与鸭子类型 |
| 工程 | 模块/异常/IO/生态/验证——从脚本到正经程序 | 11 模块与包 / 12 异常 / 13 文件IO / 14 标准库 / 15 测试调试 |

整个系列的架构主线是一条链：数据模型 → 容器 → 函数 → 类与协议 → 工程化，前后篇互为上下游；每篇讲什么不讲什么的取舍都服从「机制优先于语法」的决策——这是系列在广度与深度之间的明确边界，取舍的代价是 API 细节留给官方文档。

## 怎么读

- **零基础**：按 1-15 顺序，每篇结尾的「上手机会」当天做完；
- **会其他语言**（Java/Go/JS）：重点读 3（动态类型）、8（LEGB 作用域）、11（鸭子类型）、13（EAFP 风格）——这四篇是 Python 与静态语言**思维差异**最大的地方；
- **赶时间**：每篇「5W 速记卡」可当 10 分钟复习卡。

## 前置要求

无——第 1 篇从「什么是解释执行」讲起。有编程经验者前两篇可速读。
