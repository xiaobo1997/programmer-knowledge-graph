## 我能得到什么

- 写延迟/读延迟的毛刺能按机制归因到具体环节与参数
- 四档持久化、三级水位、采样策略的取舍能讲出依据（不是背配置）
- 建表评审能对齐 Bloom 粒度、blocksize、预分区的配套决策
- 大堆实例的 GC 与缓存容量问题有明确的演进方向（BucketCache/offheap）
