# 从零开始认识架构师软实力系列

> 技术能力决定你能走多深，软实力决定你的技术能走多远——决策留痕、方案表达、选型方法、协作影响、AI 时代的能力演进，五个专题把「非技术能力」工程化。

## 这个目录讲什么

面向后端工程师到技术负责人的转型期：ADR 决策方法、技术方案写作、选型方法论（含最易被忽略的退出成本）、跨团队协作与横向影响力、AI 时代的能力模型。每篇给可落地的清单与反例，不做鸡汤。
