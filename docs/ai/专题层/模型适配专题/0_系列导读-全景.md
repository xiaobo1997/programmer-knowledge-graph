# 模型适配专题 · 系列导读-全景

> **一句话导读**：模型到位之后，怎么把它变成你的——先判缺口（知识/行为），再选路线（RAG/微调/蒸馏），两篇正文分别讲「怎么选」与「怎么落地」。

全景导读：本系列两篇正文，一张缺口诊断图。篇 1 是选路篇，篇 2 是落地篇；读法建议先篇 1 后篇 2，因为篇 2 的开工条件正是篇 1 的诊断结论。
