## 1.1 思考：agent 治理为什么重要

agent 治理是 2026 年 AI 工程化的**核心话题**——只要你的 agent 处理真实业务（金钱 / 数据 / 权限），治理是上线前的硬性门槛。

为什么重要？

1. **agent 自主决策**——传统应用按代码逻辑执行，agent 按 LLM 推理执行，LLM 推理可能被 prompt 操纵
2. **攻击面动态**——传统应用攻击面已知（API / 端口），agent 攻击面动态（prompt injection / tool misuse）
3. **权限扩散**——agent 能调工具 = 能调 API = 能改数据 = 能删记录
4. **合规要求**——金融/医疗/政府场景，治理是合规底线

**本篇目标**：把特性层「Agent 安全治理」的 6 层政策栈 + OWASP ASI，用到风控 agent + 客服 agent 的实战中。

## 1.8 Trade-off 概览

- 安全 vs 可用性：治理越严格，可用性越低
- 合规 vs 创新：合规要求严格，创新需要灵活
- 审计 vs 效率：审计要完整，效率要性能
- 可解释性 vs 性能：可解释要代价，性能要速度
- 实时 vs 准实时：风控要实时，准实时可以容忍
