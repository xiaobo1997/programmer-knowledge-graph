# §7 审计日志 + 可观测：治理落地

## 一句话摘要

审计日志 + 可观测 的核心要点与实践指导。

**5W 速记卡**：
- **What**：审计日志 + 可观测体系
- **Why**：治理需要可观测才能发现问题
- **Who**：做了风控/客服 agent 的工程师
- **When**：设计审计日志时
- **Where**：风控 agent + 客服 agent

**自测三问**：
1. 本文核心机制：审计 = Trace + 日志 + 指标
2. 失效点：无审计 → 无法追溯
3. 与下篇衔接：审计日志 → 评估 + 演练

---

## 7.1 思考：审计为什么重要

**核心问题**：agent 审计为什么重要？

答案：agent 自主决策——决策可能有误，误决策需要追溯。不做审计，出事故无法定责，无法改进。

**审计的三个层次**：
1. **Trace**——每个决策的完整链路
2. **日志**——每个操作的记录
3. **指标**——安全指标的度量

## 7.2 审计日志结构

```mermaid

    Decision[\"Agent 决策\"] --> Trace[\"Trace<br/>决策链路\"]
    Trace --> Log[\"审计日志<br/>操作记录\"]
    Log --> Metric[\"指标<br/>安全度量\"]
    Metric --> Dashboard[\"Dashboard<br/>可视化\"]
    
    style Trace fill:#e3f2fd
    style Log fill:#fff3e0
    style Metric fill:#f3e5f5
    style Dashboard fill:#e8f5e9
```

**审计日志的 6 个字段**：
| 字段 | 说明 |
|---|---|
| timestamp | 决策时间 |
| agent_id | agent ID |
| action | 动作（查/标记/拦截/退款） |
| risk_level | 风险等级 |
| decision | 决策结果（放行/拦截/人工审核） |
| reason | 决策依据 |

## 7.3 风控 agent 审计日志

风控 agent 的审计日志：

```python
audit_log = {
    "timestamp": "2026-09-21T10:00:00Z",
    "agent_id": "risk-agent-001",
    "action": "block_transaction",
    "risk_level": "high",
    "decision": "block",
    "reason": "规则 rule_001 命中：金额 > 10000",
    "h_itl": "auto",
    "user_id": "user_123",
    "transaction_id": "txn_456"
}
```

**风控场景的审计重点**：
- 拦截决策：为什么拦截？
- 规则命中：哪条规则命中？
- LLM 判断：LLM 为什么这样判断？
- HITL 审批：谁审批的？什么时候？

## 7.4 客服 agent 审计日志

客服 agent 的审计日志：

```python
audit_log = {
    "timestamp": "2026-09-21T10:00:00Z",
    "agent_id": "service-agent-001",
    "action": "create_ticket",
    "risk_level": "low",
    "decision": "create",
    "reason": "用户咨询退款政策",
    "h_itl": "auto",
    "user_id": "user_123",
    "query": "如何退款？"
}
```

**客服场景的审计重点**：
- 回答内容：为什么这样回答？
- PII 泄露：是否泄露了敏感信息？
- HITL 审批：谁审批的？什么时候？
- 工具调用：调了什么工具？结果是什么？

## 7.5 安全指标

| 指标 | 风控场景 | 客服场景 | 目标 |
|---|---|---|---|
| 拦截准确率 | 正确拦截比例 | - | > 95% |
| 误拦率 | 误拦比例 | - | < 5% |
| 漏拦率 | 漏拦比例 | - | < 1% |
| 回答准确率 | - | 正确回答比例 | > 90% |
| 误答率 | - | 误答比例 | < 10% |
| HITL 审批率 | 人工审批比例 | 人工审批比例 | < 20% |
| PII 泄露率 | - | PII 泄露比例 | 0% |

## 7.6 可观测体系

**可观测 = Trace + 日志 + 指标 + 告警**

| 层级 | 内容 | 风控场景 | 客服场景 |
|---|---|---|---|
| Trace | 决策链路 | 拦截决策链路 | 回答决策链路 |
| 日志 | 操作记录 | 拦截操作记录 | 回答操作记录 |
| 指标 | 安全度量 | 拦截准确率 | 回答准确率 |
| 告警 | 异常告警 | 异常拦截告警 | 异常回答告警 |
