## 一句话摘要

数据与事实声明 的核心要点与实践指导。

**5W 速记卡**：
- **What**：数据来源 + 事实声明 + 参考资料
- **Why**：让读者知道数据可信
- **Who**：读者
- **When**：写完后

1. 本文核心机制：数据声明 = star 数来源 + 日期 + 引用
