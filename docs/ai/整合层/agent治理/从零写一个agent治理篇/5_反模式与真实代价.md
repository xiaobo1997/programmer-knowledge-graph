# §5 反模式 + 真实代价：治理避坑

## 一句话摘要

反模式 + 真实代价 的核心要点与实践指导。

**5W 速记卡**：
- **What**：4 大反模式 + 真实代价 + 正确做法
- **Why**：反模式 = 治理失败根因
- **Who**：做了风控/客服 agent 的工程师
- **When**：设计治理架构时
- **Where**：风控 agent + 客服 agent

**自测三问**：
1. 本文核心机制：4 大反模式 = sandbox-only + 无 HITL + 无审计 + 无 OWASP
2. 失效点：反模式 → 安全事故
3. 与下篇衔接：反模式 → 权限分级 + HITL

---

## 5.1 思考：为什么有反模式

**核心问题**：agent 治理的常见错误是什么？

答案：治理最常见的错误是「只做一层防护」——比如只 sandbox 其他不管。或者「不做 HITL」——高风险动作 agent 自动执行。

**4 大反模式**：
1. **sandbox-only**——只 sandbox 其他不管
2. **no-HITL**——高风险动作 agent 自动执行
3. **no-audit**——不做审计日志
4. **no-OWASP**——不做持续威胁评估

**核心口诀**：**单层防御 = 必被绕过，多层协同 = 纵深防御。**

## 5.2 反模式 1：sandbox-only

**表现**：只做 L3 OS sandbox，其他层不管。

**真实案例**：
- agent sandbox 隔离了，但权限没分级——agent 可以调任何工具
- agent sandbox 隔离了，但没做 HITL——高风险动作自动执行
- agent sandbox 隔离了，但没做审计——决策无留痕

**代价**：sandbox 防住了系统攻击，但防不住 prompt injection + 权限滥用 + 决策风险。

**正确做法**：6 层政策栈协同，不是只 sandbox。

## 5.3 反模式 2：no-HITL

**表现**：高风险动作 agent 自动执行，不做人审。

**真实案例**：
- agent 自动拦截交易——没有人工审批
- agent 自动冻结账户——没有人工审批
- agent 自动退款——没有人工审批

**代价**：agent 判断错误 → 直接执行 → 金钱损失 / 数据泄露。

**正确做法**：L2/L3 动作必须 HITL 审批。

## 5.4 反模式 3：no-audit

**表现**：不做审计日志——决策无留痕。

**真实案例**：
- agent 拦截了交易——但没记录为什么拦截
- agent 创建了工单——但没记录谁做的决定
- agent 调用了工具——但没记录工具结果

**代价**：出事故无法追溯，无法定责，无法改进。

**正确做法**：每个决策 + 每个权限检查 + 每个 HITL 审批都留审计日志。

## 5.5 反模式 4：no-OWASP

**表现**：不做持续威胁评估——不知道新威胁。

**真实案例**：
- OWASP 发布了新威胁——但 agent 没更新防护
- 红队演练发现了新漏洞——但 agent 没修复
- prompt injection 攻击成功了——但 agent 没记录

**代价**：新威胁出现 → agent 被攻击 → 安全事故。

**正确做法**：季度审计 + 新威胁响应 + 红队演练。

## 5.6 4 大反模式对比表

| 反模式 | 表现 | 代价 | 正确做法 |
|---|---|---|---|
| **sandbox-only** | 只 sandbox | 防不住 prompt injection + 权限滥用 | 6 层协同 |
| **no-HITL** | 高风险自动执行 | 金钱损失 / 数据泄露 | L2/L3 必须 HITL |
| **no-audit** | 无审计日志 | 无法追溯定责 | 每个决策留痕 |
| **no-OWASP** | 不做持续评估 | 新威胁被攻击 | 季度审计 + 红队 |

## 5.7 风控场景的反模式

| 反模式 | 风控场景表现 | 风控场景代价 |
|---|---|---|
| sandbox-only | 只 sandbox，权限没分级 | agent 调了不该调的工具 |
| no-HITL | 拦截交易自动执行 | 误拦 → 客户投诉 |
| no-audit | 拦截决策无留痕 | 无法追溯为什么拦截 |
| no-OWASP | prompt injection 成功 | agent 被操纵放行风险交易 |

## 5.8 客服场景的反模式

| 反模式 | 客服场景表现 | 客服场景代价 |
|---|---|---|
| sandbox-only | 只 sandbox，权限没分级 | agent 调了不该调的工具 |
| no-HITL | 退款自动执行 | 误退 → 金钱损失 |
| no-audit | 回答无留痕 | 无法追溯为什么这样回答 |
| no-OWASP | PII 泄露 | 用户数据泄露 |
