---\n\n# §6 从 demo 到生产工具的演进之路思考

**5W 速记卡**：
- **What**：Demo → 生产的演进路径（能力→用例→方案→流程→差距）
- **Why**：Demo 能跑 ≠ 生产能用，差距就是演进方向
- **Who**：想把自己的 RAG demo 推进到生产的人
- **When**：实现完后的演进规划
- **Where**：V1 白盒 → V2 换组件 → V3 服务化 → V4 生产级


**自测三问**：
1. 本文核心机制：能力决定用例 → 用例决定方案 → 方案改变流程
2. 失效点：跳阶段（直接 V3 服务化）→ 基础不牢
3. 与下篇衔接：演进思考 → 最终架构图 + 亮点

## 6.2 能力演进

| 能力 | Demo 版 | 生产版 |
|---|---|---|
| 文档加载 | 单文件 | 多源（DB/API/消息） |
| 分块 | 固定大小 | 自适应分块 |
| 向量化 | 单模型 | 多模型融合 |
| 向量存储 | ChromaDB | Milvus 集群 |
| 检索 | 向量+关键词 | 多策略融合 |
| 重排 | 单模型 | 多模型级联 |
| 生成 | 单 LLM | 多 LLM 路由 |
| 评估 | 无 | RAGAS 自动评估 |
\n## 6.3 功能用例演进

| 功能用例 | Demo | 生产 |
|---|---|---|
| 业务问答 | 单轮问答 | 多轮 + 上下文记忆 |
| 费率查询 | 精确检索 | 模糊 + 精确混合 |
| 合规问答 | 知识库检索 | 知识库 + 规则引擎 |
| 拒付流程 | 文档检索 | 文档 + 工单系统 |
\n## 6.4 技术方案演进

**白盒 → 黑盒直观对比**：

| 方案 | 原理 | 精度 | 延迟 | 成本 |
|---|---|---|---|---|
| TF-IDF | 词重合 | 低 | 快 | 低 |
| Embedding | 语义相近 | 中 | 中 | 中 |
| Cross-encoder | 交互式 | 高 | 慢 | 高 |
| Reranker | 精排 | 最高 | 最慢 | 最高 |

**V1 白盒 → V2 换组件 → V3 服务化 → V4 生产级**：
- 骨架不动，血肉换新
- 一次只调一个变量

## 6.5 流程演进

| 流程 | Demo | 生产 |
|---|---|---|
| 开发 | 手写 | 框架 + 定制 |
| 测试 | 手动 | 自动化（RAGAS） |
| 发布 | 手动 | CI/CD |
| 运维 | 人工 | 可观测 + 自动扩缩 |
\n## 6.6 落地差距

**差距清单**：

| 差距 | 依据来源 | 影响 |
|---|---|---|
| 无多轮对话 | 行业惯例 | 复杂问题无法拆解 |
| 无评估闭环 | 官方文档 | 无法度量检索质量 |
| 无权限控制 | 生产需求 | 敏感文档泄露风险 |
| 无审计日志 | 合规要求 | 无法追溯回答来源 |
| 向量化依赖 API | 网络依赖 | 离线不可用 |

**明确哪些是 demo 刻意简化的**：
- 多轮对话：学习目的，先理解单轮
- 评估闭环：后续 V2 接入 RAGAS
- 权限控制：生产必备，demo 简化

## 6.8 demo 可迁移资产

**哪些东西直接搬进生产**：

1. **分块策略**：chunk 大小 + 重叠，通用
2. **检查链**：每个模块有输入/输出检查，通用
3. **评估闭环**：RAGAS 评估框架，通用
4. **混合检索**：向量 + 关键词，通用
5. **重排思维**：粗排 + 精排，通用

**demo 不是白做的**——学的东西能直接用在生产环境。

## 6.9 演进路线图

| 阶段 | 改什么 | 不改什么 |
|---|---|---|
| V1 白盒 | 从零手写全链路 | 骨架 |
| V2 换组件 | 换向量化/检索/重排 | 流程 |
| V3 服务化 | API 化 + Web 界面 | 核心算法 |
| V4 生产级 | 多用户 + 并发 + 安全 | 架构 |

**每阶段一张「改什么 + 不改什么」表**——骨架不动血肉换新。

## 6.10 生产路径

**demo → 生产的演进路径**：
1. **代码重构**：模块化 + 类型注解 + 错误处理
2. **测试覆盖**：单元测试 + 集成测试 + RAGAS 评估
3. **部署上线**：Docker + K8s + 可观测
4. **持续迭代**：监控 + 告警 + 自动扩缩

## 6.11 已知局限

- 本 demo 是学习载体，不等于生产系统
- 未覆盖多模态检索（图片/PDF 表格）
- 未覆盖 Agentic RAG（检索 + 工具调用 + 生成一体化）
- 未覆盖生产级安全（权限/审计/合规）
