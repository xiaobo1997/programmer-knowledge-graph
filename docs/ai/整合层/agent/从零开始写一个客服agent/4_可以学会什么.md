# §4 可以学会什么：客服 agent 核心能力

## 一句话摘要

可以学会什么 的核心要点与实践指导。

**5W 速记卡**：
- **What**：客服 agent 核心能力清单
- **Why**：理解每个能力解决什么问题
- **Who**：想做客服 agent 的工程师
- **When**：实现前先理解能力
- **Where**：本地开发环境

**自测三问**：
1. 本文核心机制：客服 agent = 多轮对话 + RAG + 工具调用
2. 失效点：单轮问答无法解决复杂问题
3. 与下篇衔接：可以学会什么 → 实现方案

## 4.1 客服 agent 核心能力

| # | 能力 | 解决什么问题 | 复刻程度 |
|---|---|---|---|
| 1 | RAG 知识库 | 文档怎么检索+生成？ | ✅ 复刻 |
| 2 | 多轮对话 | 用户追问怎么处理？ | ✅ 复刻 |
| 3 | 工具调用 | 查订单/查费率/查结算/创建工单？ | ✅ 复刻 |
| 4 | 权限分级 | 高风险动作需要审批？ | ✅ 复刻 |
| 5 | 上下文管理 | 多轮对话状态怎么维护？ | ✅ 复刻 |
| 6 | 审计日志 | 每个决策需要留痕？ | ✅ 复刻 |
| 7 | SubAgent / Git Worktree | 复杂度高，与核心学习目标无关 | ❌ 跳过 |

## 4.2 RAG 知识库

**核心**：文档加载 → 分块 → 向量化 → 检索 → 生成

RAG 做什么：
- 加载业务文档（费率表/结算规则/拒付流程）
- 分块（递归字符分块 500字+50重叠）
- 向量化（TF-IDF 词频向量）
- 检索（余弦相似度 Top-K）
- 生成（带来源的回答）

RAG 不做什么：
- 不做多轮对话（RAG 只检索，不管理对话状态）
- 不做工具调用（RAG 只检索，不查外部数据）

## 4.3 多轮对话

**核心**：追问澄清 → 确认意图 → 执行动作

多轮对话做什么：
- 用户提问 → 意图理解
- 意图不明确 → 追问澄清
- 意图明确 → 执行动作（查订单/查费率/创建工单）

多轮对话不做什么：
- 不做知识库检索（检索是 RAG 的事）
- 不做权限检查（权限是策略层的事）

## 4.4 工具调用

**核心**：查订单/查费率/查结算/创建工单

工具调用做什么：
- 查订单（交易状态）
- 查费率（费率表）
- 查结算（结算规则）
- 创建工单（转人工）

工具调用不做什么：
- 不做知识库检索（工具只查外部数据）
- 不做权限检查（工具调用前需要权限检查）

## 4.5 权限分级

**核心**：L0-L3 + HITL 决策树

权限分级做什么：
- L0 只读（查数据）
- L1 写业务数据（创建工单）
- L2 外部副作用（退款/转账）
- L3 系统级（删除数据）

权限分级不做什么：
- 不做知识库检索（权限只控制动作）
- 不做多轮对话（权限不管理对话状态）

## 4.6 上下文管理

**核心**：多轮对话状态维护

上下文管理做什么：
- 维护对话历史（最近 N 轮）
- 上下文压缩（超过窗口时摘要）
- 上下文组装（生成 prompt 时注入历史）

上下文管理不做什么：
- 不做知识库检索（上下文只管理对话状态）
- 不做权限检查（上下文不控制权限）

## 4.7 审计日志

**核心**：完整记录每个决策依据

审计日志做什么：
- 记录每个决策（RAG/LLM/工具）
- 记录每个权限检查（通过/拒绝）
- 记录每个 HITL 审批（通过/拒绝）

审计日志不做什么：
- 不做知识库检索（审计只记录）
- 不做权限检查（审计不控制权限）
