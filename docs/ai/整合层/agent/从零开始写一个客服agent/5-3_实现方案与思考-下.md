## 5.7 组装（命令级）

**组装是什么？**——把各个文件组装成完整的系统。

组装做什么：
- CLI 入口 → RAG 检索 → LLM 生成 → 动作执行 → 审计日志
- 命令级组装（最小可用）

组装不做什么：
- 不做风险判断（组装只是连接各模块）
- 不做权限检查（组装不控制权限）

**组装的实现**：

```python
# main.py - 组装
def main():
    """主入口"""
    # 1. 用户提问
    query = cli_input()
    
    # 2. RAG 检索
    rag_result = rag_engine(query)
    
    # 3. LLM 生成
    llm_result = llm_generate(query, rag_result)
    
    # 4. 动作执行
    action = execute_action(llm_result)
    
    # 5. 审计日志
    audit_log(query, rag_result, llm_result, action)
    
    # 6. 输出
    return action
```

## 5.8 结果验收

**结果验收是什么？**——验证每个模块是否正常工作。

结果验收做什么：
- 最小闭环能跑通（用户提问 → RAG 检索 → LLM 生成 → 回答）
- RAG 能检索（命中知识库 → 返回来源）
- LLM 能生成（带来源的回答）
- 多轮对话能追问（意图不明确 → 追问澄清）
- 工具调用能查数据（查订单/查费率/查结算/创建工单）
- 权限分级能控制动作（L0-L3 + HITL 决策树）
- 审计日志能记录（记录完整决策依据）

结果验收不做什么：
- 不做风险判断（验收只验证功能）
- 不做权限检查（验收不控制权限）

**验收清单**：

| 验收项 | 验证方法 | 预期结果 | 优先级 |
|---|---|---|---|
| 最小闭环 | 运行 CLI 入口 | 交易 → 风险判断 → 动作 | P0 |
| 规则引擎 | 命中规则 | 返回风险等级 | P0 |
| LLM 判断 | 规则不够时 | 返回 LLM 判断 + 依据 | P1 |
| 多轮对话 | 意图不明确 | 追问澄清 | P0 |
| 工具调用 | 查外部数据 | 返回工具结果 + 来源 | P1 |
| 权限分级 | 高风险动作 | 检查权限 + HITL 审批 | P0 |
| 审计日志 | 每个决策 | 记录完整决策依据 | P0 |
