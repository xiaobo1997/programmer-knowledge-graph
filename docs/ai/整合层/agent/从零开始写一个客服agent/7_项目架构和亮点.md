# §7 项目架构和亮点

## 一句话摘要

项目架构和亮点 的核心要点与实践指导。

**5W 速记卡**：
- **What**：客服 agent 最终架构 + 4-5 亮点
- **Why**：理解整体架构 + 亮点价值
- **Who**：想从零手写客服 agent 的工程师
- **When**：开发完系统后
- **Where**：本地开发环境

**自测三问**：
1. 本文核心机制：最终架构 = 入口层 + 客服核心层 + 资源层

## 7.2 4-5 亮点

**亮点 1：RAG + 多轮对话混合**
- RAG 检索知识库（已知问题），多轮对话澄清意图（未知问题）
- 兼顾准确率与灵活
- 这是生产级客服 agent 的核心模式

**亮点 2：多轮对话（追问澄清）**
- 意图不明确时追问澄清
- 追问澄清 → 确认意图 → 执行动作
- 降低误答率

**亮点 3：权限分级（L0-L3 + HITL 决策树）**
- L0 只读 / L1 查询 / L2 动作 / L3 人工审核
- HITL 决策树：4 类风险 × 3 类审批人
- 纵深防御

**亮点 4：审计日志（完整记录每个决策依据）**
- 记录每个决策（RAG/LLM/工具）
- 记录每个权限检查（通过/拒绝）
- 记录每个 HITL 审批（通过/拒绝）
- 合规底线

**亮点 5：从零实现（零依赖 + requests 唯一外部依赖）**
- 纯 Python 从零实现
- 不依赖 LangChain / LlamaIndex
- 可复刻、可控、可解释
