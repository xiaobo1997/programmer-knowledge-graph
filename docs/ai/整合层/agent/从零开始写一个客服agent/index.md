## 📚 学习路线（先理解门道，再写代码）

> 写作顺序不是从 §1 开始，而是先建立客服 agent 全景认知，再逐段推进。
> 每一段对应一个「搞懂的问题」，搞懂了再写。

| 阶段 | 搞懂的问题 | 对应章节 |
|---|---|---|
| ① 全景 | 客服 agent 是什么？为什么需要 agent 做客服？ | §1 + §2 |
| ② 原理 | RAG 怎么检索+生成？多轮对话怎么追问？ | §3（原理部分） |
| ③ 环节 | RAG/对话/工具/权限各环节解决什么问题？ | §3 + §5 |
| ④ 动手 | 最小闭环怎么跑通？每个环节代码怎么组织？ | §5 |
| ⑤ 演进 | demo 到生产差在哪？客服系统 + agent 决策怎么融合？ | §6 + §10 |
| ⑥ 沉淀 | 文档怎么建设？参考资料怎么留？ | §8 + §9 |

**先理解的核心概念（每个都要能用自己的话讲出来）**：
- [ ] 客服 agent 是什么、为什么需要（多轮追问 + 知识库 + 动作执行）
- [ ] RAG 原理（检索+生成，带来源）
- [ ] 多轮对话（追问澄清 → 确认意图 → 执行动作）
- [ ] 工具调用（查订单/查费率/查结算/创建工单）
- [ ] 权限分级（L0-L3 + HITL 决策树）
