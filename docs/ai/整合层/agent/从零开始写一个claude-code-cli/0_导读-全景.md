# 从零开始写一个 claude-code-cli · 系列导读

> **本文是哪个系列的导读**：整合层 agent demo 工程「从零开始写一个 claude-code-cli」的入口。
> **配套代码**：program-code-example/agent/claude-code-cli-from-scratch/
> **完整流程**：先读本导读 → 按 §1-§10 顺序学习 → 看四件套 → 跑代码

## 一句话摘要

**从零复刻 claude-code 的核心能力**——用 Python 手写一个"麻雀虽小五脏俱全"的 CLI agent（6 大工具 + ReAct Loop + 5 层权限 + 会话恢复），不依赖任何 agent 框架。目标是理解 agent 是怎么运作的 + 提高动手能力，不是做出产品。

## 能力点清单（要复刻什么）

| # | 能力 | 复刻程度 | 说明 |
|---|---|---|---|
| 1 | 6 大核心工具（ReadFile/WriteFile/EditFile/Bash/Glob/Grep）| ✅ 复刻 | 核心，可独立验证 |
| 2 | Agent Loop（ReAct 模式）| ✅ 复刻 | agent 的灵魂 |
| 3 | 5 层权限防御 | ✅ 复刻 | 纵深防御思想 |
| 4 | Slash Command + Skill | ✅ 复刻 | 命令框架 |
| 5 | 会话持久化（resume）| ✅ 复刻 | 跨会话记忆 |
| 6 | MCP 协议 | ⚠️ 简化 | 注册表模拟概念 |
| 7 | Hook 生命周期 | ⚠️ 简化 | 关键 3 个 |
| 8 | 上下文压缩 | ⚠️ 简化 | token 计数 + 截断 |
| 9 | SubAgent / Git Worktree / Agent Teams | ❌ 跳过 | 复杂度高，与核心学习目标无关 |

**决策逻辑**：复刻 = 理解核心；简化 = 展示概念；跳过 = 避免被次要特性拖累（详见 §2）。
