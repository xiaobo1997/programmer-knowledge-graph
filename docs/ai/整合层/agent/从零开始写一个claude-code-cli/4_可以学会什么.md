# §4 可以学会什么

> **系列**：从零开始写一个 claude-code-cli（整合层 demo 工程）

---

## 读完这个 demo（wiki + 代码 + 四件套），你能获得的能力

### 能力 1：能独立设计一个 Agent Loop（ReAct 模式）

- **能做什么**：从零写出"思考 → 行动 → 观察"的自主循环，让 LLM 不再是"一次问答"而是"多轮自主完成任务"
- **理解**：为什么 agent 需要循环？循环的终止条件怎么设计？怎么防止死循环？
- **可验证**：写完能跑一个"让 agent 读文件并总结"的完整任务

### 能力 2：能实现工具调用的完整链路

- **能做什么**：定义工具 Schema → 让 LLM 选择工具 → 校验参数 → 执行 → 结果回传
- **理解**：工具描述怎么写 LLM 才选对？参数校验怎么防 LLM 幻觉参数？
- **可验证**：实现 6 大工具（ReadFile/WriteFile/EditFile/Bash/Glob/Grep）且能被 LLM 正确调用

### 能力 3：能设计 5 层权限防御体系

- **能做什么**：工具白名单 → 目录边界 → 命令黑名单 → 危险操作拦截 → 人工确认
- **理解**：为什么 agent 必须有权限控制？LLM 为什么不能信任？每层防什么？
- **可验证**：`删除所有文件` 被拦截；`rm -rf` 被拦截；目录外访问被拒

### 能力 4：能管理 agent 的上下文（压缩 + 跨会话记忆）

- **能做什么**：token 计数 → 长对话摘要压缩 → 会话 JSON 持久化 → `--resume` 恢复
- **理解**：为什么 agent 会话会爆 token？压缩怎么不丢关键信息？
- **可验证**：长对话后 token 不超限；重启后 `--resume` 能继续

### 能力 5：能评估 agent 工程化的生产差距（demo vs 生产）

- **能做什么**：对照生产级工具（claude-code 142k⭐），清楚自己的 demo 缺什么（并发/安全/分发/可观测）
- **理解**：能力 → 功能用例 → 技术方案 → 流程 → 落地差距的演进链
- **可验证**：能说出"如果我把 demo 变成产品，要改哪 5 件事"

---

## 与场景 / 业务的关联

| 能力 | 后端业务场景（信贷 / 支付）|
|---|---|
| Agent Loop | 自动化风控流程编排 / 多步审核自动化 |
| 工具调用 | 让 agent 调用内部 API / 数据库查询 |
| 权限防御 | agent 访问客户数据必须有边界（合规刚需）|
| 上下文管理 | 长会话客服 agent 的成本控制 |
| 生产差距评估 | 判断内部工具"能用 vs 能上线"的差距 |

## 一句话总结

**做完这个 demo，你从"会用 agent 工具"变成"能写 agent 工具"**——核心是 Agent Loop + 工具调用 + 权限 + 上下文四件事，以及"麻雀虽小五脏俱全"的工程判断力。
