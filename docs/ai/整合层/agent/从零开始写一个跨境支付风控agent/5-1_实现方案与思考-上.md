# §5-1 实现方案与思考（上）：最小闭环 + 全局地图 + 规则引擎

## 一句话摘要

实现方案与思考（上） 的核心要点与实践指导。

**5W 速记卡**：
- **What**：风控 agent 从零实现（上）——最小闭环 + 全局地图 + 规则引擎
- **Why**：先跑通最小闭环，再逐步完善
- **Who**：想从零手写风控 agent 的工程师
- **When**：实现阶段（上）
- **Where**：本地开发环境

**自测三问**：
1. 本文核心机制：最小闭环 = 交易输入 → 风险判断 → 动作执行
2. 失效点：规则引擎无法覆盖的异常模式 → LLM 判断
3. 与下篇衔接：最小闭环 → 多轮对话 + 工具调用

---

## 5.0 最小闭环（2 文件：交易 → 风险判断 → 动作）

**最小闭环是什么？**——只保留风控 agent 最核心的环节：

```
交易输入 → 规则引擎 → LLM 判断 → 动作执行（拦截/放行/人工审核）
```

**为什么从最小闭环开始？**——先跑通一个能工作的闭环，再逐步加能力。最小闭环只有 2 个文件：
1. `risk_engine.py`：规则引擎 + LLM 判断
2. `action.py`：动作执行（拦截/放行/人工审核）

**最小闭环的局限**：不能做多轮确认、不能查外部数据、不能审计。但这不影响"跑通"——先跑通，再完善。

**最小闭环的实现要点**：
- 规则引擎：Python 字典 + 条件判断（零依赖）
- LLM 判断：requests 调用 OpenAI API（唯一外部依赖）
- 动作执行：打印日志（demo 级）
- 权限分级：代码里 if/else（demo 级）
- 审计日志：写文件（demo 级）

## 5.1 全局地图（自上而下：7 文件 / 5 步数据流）

**全局地图是什么？**——从零实现时，先画一张图——知道要写多少文件、每一步做什么。

```mermaid
flowchart TB
    A[\"交易输入\"] --> B[\"意图理解<br/>问题向量化\"]
    B --> C[\"规则引擎<br/>规则匹配 + 例外处理\"]
    C --> D[\"LLM 判断<br/>风险等级 + 建议动作\"]
    D --> E[\"动作执行<br/>拦截/放行/人工审核\"]
    E --> F[\"审计日志<br/>记录完整决策依据\"]
    F --> G[\"输出<br/>风险等级 + 建议动作\"]
```

**7 文件 / 5 步数据流**：

| # | 文件 | 职责 | 数据 |
|---|---|---|---|
| 1 | `cli.py` | 入口：交易输入 | 交易数据 |
| 2 | `risk_engine.py` | 规则引擎 + LLM 判断 | 规则结果 + LLM 判断 |
| 3 | `rules.py` | 规则定义 | 规则表 |
| 4 | `actions.py` | 动作执行 | 动作结果 |
| 5 | `audit.py` | 审计日志 | 审计记录 |
| 6 | `tools.py` | 工具调用 | 工具结果 |
| 7 | `config.py` | 配置 | API Key + 规则配置 |

**5 步数据流**：
1. 交易输入 → 意图理解（解析交易数据）
2. 意图理解 → 规则引擎（匹配规则）
3. 规则引擎 → LLM 判断（规则不够时）
4. LLM 判断 → 动作执行（执行动作）
5. 动作执行 → 审计日志（记录决策）

## 5.2 风控知识库构建与规则引擎

**风控知识库是什么？**——把风控规则沉淀成知识库，让 agent 自动判断风险等级。

风控知识库包含：
- 规则表（金额/币种/国家/渠道）
- 黑名单（高风险用户/商户）
- 合规政策（跨境合规要求）

**规则引擎是什么？**——规则匹配 + 例外处理。

规则引擎做什么：
- 匹配交易属性（金额/币种/国家/渠道）
- 命中规则 → 返回风险等级
- 例外处理（规则冲突时怎么选）

规则引擎不做什么：
- 不做 LLM 判断（规则覆盖不了时交给 LLM）
- 不做工具调用（规则匹配不需要外部数据）

**规则引擎的实现**：

```python
# rules.py - 规则定义
RULES = [
    {
        "id": "rule_001",
        "name": "大额交易",
        "condition": "amount > 10000",
        "risk_level": "high",
        "action": "人工审核",
    },
    {
        "id": "rule_002",
        "name": "黑名单交易",
        "condition": "user_id in BLACKLIST",
        "risk_level": "critical",
        "action": "拦截",
    },
]
```
