# §4 可以学会什么：风控 agent 核心能力

## 一句话摘要

可以学会什么 的核心要点与实践指导。

**5W 速记卡**：
- **What**：风控 agent 核心能力清单
- **Why**：理解每个能力解决什么问题
- **Who**：想做风控 agent 的工程师
- **When**：实现前先理解能力
- **Where**：本地开发环境

**自测三问**：
1. 本文核心机制：风控 agent = 规则引擎 + LLM 判断 + 动作执行
2. 失效点：规则引擎无法覆盖的异常模式
3. 与下篇衔接：可以学会什么 → 实现方案

## 4.1 风控 agent 核心能力

| # | 能力 | 解决什么问题 | 复刻程度 |
|---|---|---|---|
| 1 | 规则引擎 | 固定规则怎么匹配交易？ | ✅ 复刻 |
| 2 | LLM 风险判断 | 规则无法覆盖的异常模式？ | ✅ 复刻 |
| 3 | 多轮确认 | 可疑交易需要追问澄清？ | ✅ 复刻 |
| 4 | 工具调用 | 查黑名单/查交易历史/查合规政策？ | ✅ 复刻 |

## 4.2 规则引擎

**核心**：规则匹配 + 例外处理

规则引擎做什么：
- 匹配交易属性（金额/币种/国家/渠道）
- 命中规则 → 返回风险等级
- 例外处理（规则冲突时怎么选）

规则引擎不做什么：
- 不做 LLM 判断（规则覆盖不了时交给 LLM）
- 不做工具调用（规则匹配不需要外部数据）

## 4.3 LLM 风险判断

**核心**：LLM 做风险判断 + 多轮确认

LLM 判断做什么：
- 规则无法覆盖时做风险判断
- 可疑交易做多轮确认（追问澄清）
- 返回风险等级 + 建议动作

LLM 判断不做什么：
- 不替代规则引擎（规则覆盖的先走规则）
- 不做工具调用（LLM 只做判断，不查数据）

## 4.4 工具调用

**核心**：查黑名单/查交易历史/查合规政策

工具调用做什么：
- 查黑名单（命中黑名单 → 高风险）
- 查交易历史（历史异常 → 高风险）
- 查合规政策（合规检查 → 低风险）

工具调用不做什么：
- 不做风险判断（工具只返回数据，不做判断）
- 不做权限检查（工具调用前需要权限检查）

## 4.5 权限分级

**核心**：L0-L3 + HITL 决策树

权限分级做什么：
- L0 只读（查数据）
- L1 写业务数据（标记风险）
- L2 外部副作用（拦截交易）
- L3 系统级（放行人工审核）

权限分级不做什么：
- 不做风险判断（权限只控制动作，不做判断）
- 不做审计日志（权限检查后需要审计）

## 4.6 审计日志

**核心**：完整记录每个决策依据

审计日志做什么：
- 记录每个决策（规则/LLM/工具）
- 记录每个权限检查（通过/拒绝）
- 记录每个 HITL 审批（通过/拒绝）

审计日志不做什么：
- 不做风险判断（审计只记录，不做判断）
- 不做权限检查（审计不控制权限）
