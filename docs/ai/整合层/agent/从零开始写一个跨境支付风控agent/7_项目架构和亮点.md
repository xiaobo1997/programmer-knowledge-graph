## 7.2 4-5 亮点

**亮点 1：规则引擎 + LLM 混合决策**
- 规则引擎优先（已知风险），LLM 兜底（未知风险）
- 兼顾速度与灵活
- 这是生产级风控 agent 的核心模式

**亮点 2：多轮确认（追问澄清）**
- 可疑交易做多轮确认
- 追问澄清 → 确认风险 → 决策放行/拦截
- 降低误拦率

**亮点 3：权限分级（L0-L3 + HITL 决策树）**
- L0 只读 / L1 标记 / L2 拦截 / L3 放行人工审核
- HITL 决策树：4 类风险 × 3 类审批人
- 纵深防御

**亮点 4：审计日志（完整记录每个决策依据）**
- 记录每个决策（规则/LLM/工具）
- 记录每个权限检查（通过/拒绝）
- 记录每个 HITL 审批（通过/拒绝）
- 合规底线

**亮点 5：从零实现（零依赖 + requests 唯一外部依赖）**
- 纯 Python 从零实现
- 不依赖 LangChain / LlamaIndex
- 可复刻、可控、可解释
