## 9.3 系列完结：从「看懂」到「动手」

全系列到这就结束了。回顾这个系列交付的东西：

- **一条链路**：提问 → 检索 → 组装 → 生成 → 带依据回答，每个环节都能讲清为什么（§5/§7）
- **一套数据**：白盒手算、阈值拦截、Recall@3 93.3%——每个数字都能复现（§5）
- **一个方向**：V1 白盒 → V4 生产级，知道差距在哪、下一步改什么（§6）
- **一份文档**：README/贡献/已知问题/roadmap 五件套，demo 变成能交的项目（§8）

但系列写完了，学习没完。三种继续方式，按投入从低到高：

1. **跟着敲一遍**：按 §5 的 7 个文件顺序自己实现一遍——写的过程就是理解的过程，这是系列的初衷。
2. **换一个场景**：把知识库从跨境收单支付换成你熟悉的领域（信贷、电商、运维手册），数据流一行不用改——这一步验证你学到的是「机制」而不是「背答案」。
3. **走演进路线**：按 §6 的 V2（换 Embedding + 向量库）动手改造，用 §8 的评估门槛验收改动——这一步把你从「会写 demo」推向「会做工程」。

祝动手顺利。
