## 核心命题

> AI 是工具，但不是自解释的——怎么用、怎么治理、怎么发现问题。

## 关键方法论

1. **文档即契约**：代码必须符合文档
2. **AI 是工具**：AI 加速 + 人工决策
3. **知识库是资产**：持续沉淀，不是一次性
4. **主动 + 被动识别**：不只是被动等待
5. **全链路可观测**：Trace + 日志 + 指标 + 告警
