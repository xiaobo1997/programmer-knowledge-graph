# AI 应用实战 · SDD 篇

## 一句话摘要

SDD 篇帮助程序员在 AI 辅助开发中保证文档先行、搭建业务知识库和个人知识库、建立持续产出体系。

**5W 速记卡**：
- **What**：SDD = 文档先行 + AI 辅助 + 知识库 + 持续产出
- **Why**：AI 加速开发但文档滞后 → 技术债 + 知识断层
- **Who**：用 AI 做开发的工程师 + 团队leader
- **When**：设计 SDD 工作流时
- **Where**：团队 + 个人

**自测三问**：
1. 本文核心机制：SDD = 文档先行 + AI 辅助 + 知识库 + 持续产出
2. 失效点：文档滞后 → 技术债 → 知识断层
3. 与安全篇衔接：SDD（怎么用） + 安全（怎么治理）

## 核心命题

> AI 是工具，但不是自解释的——怎么用、怎么治理、怎么发现问题。

## 7 篇核心内容

1. **为什么写** —— AI 辅助开发的隐形成本 + SDD 是什么
2. **SDD 全景** —— 文档先行 + AI 辅助 + 知识库 + 持续产出全景图
3. **业务知识库搭建** —— 团队共享知识库（规则 + 模型 + 决策 + 经验）
4. **个人知识库搭建** —— 个人沉淀知识库（笔记 + 复盘 + 工具链）
5. **文档先行** —— 代码变更 → 文档同步机制
6. **持续产出体系** —— 迭代 + 复盘 + 知识库更新
7. **总结与展望** —— 回顾 + 展望 + 下一步行动

## 关键方法论

1. **文档即契约**：代码必须符合文档
2. **AI 是工具**：AI 加速 + 人工决策
3. **知识库是资产**：持续沉淀，不是一次性
4. **持续产出**：小步快跑，不是冲刺
