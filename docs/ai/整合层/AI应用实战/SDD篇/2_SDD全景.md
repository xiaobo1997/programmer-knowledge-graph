# §2 SDD 全景：文档先行 + AI 辅助 + 知识库

## 一句话摘要

SDD 全景 的核心要点与实践指导。

**5W 速记卡**：
- **What**：SDD 工作流全景 = 文档先行 + AI 辅助 + 知识库 + 持续产出
- **Why**：文档先行是 SDD 核心
- **Who**：用 AI 做开发的工程师 + 团队leader
- **When**：设计 SDD 工作流时
- **Where**：团队 + 个人

**自测三问**：
1. 本文核心机制：SDD = 文档先行 → AI 辅助 → 知识库沉淀 → 持续产出
2. 失效点：文档滞后 → 技术债
3. 与下篇衔接：SDD 全景 → 业务知识库搭建

## 2.2 文档先行（核心）

**文档先行是什么？**——先写文档，再写代码，文档即契约。

文档先行做什么：
- 需求文档（做什么）
- 设计文档（怎么做）
- 接口文档（怎么调）

文档先行不做什么：
- 不做代码（代码是 AI 辅助生成）
- 不做测试（测试是验证）

**文档先行的关键点**：
- 文档是代码的契约（代码必须符合文档）
- 文档变更 → 代码同步
- 代码变更 → 文档更新

## 2.3 AI 辅助（加速）

**AI 辅助是什么？**——AI 帮你写代码，不是替你做决策。

AI 辅助做什么：
- 代码生成（按文档生成）
- 代码审查（检查质量）
- 重构建议（优化代码）
- 文档生成（代码 → 文档）

AI 辅助不做什么：
- 不做需求决策（需求是人的事）
- 不做架构设计（架构是人的事）

## 2.4 知识库（沉淀）

**知识库是什么？**——把项目知识沉淀下来，让团队共享。

知识库包含：
- 业务知识（业务规则 + 领域模型）
- 技术知识（架构 + 设计 + 接口）
- 决策知识（为什么这样选）
- 经验知识（踩坑 + 最佳实践）

知识库不包含：
- 不含代码（代码在仓库）
- 不含文档（文档在仓库）

## 2.5 持续产出（迭代）

**持续产出是什么？**——团队 + 个人持续产出，不是冲刺。

持续产出包含：
- 迭代（小步快跑）
- 复盘（总结经验）
- 知识库更新（沉淀新知识）

持续产出不包含：
- 不含一次性交付
- 不含个人英雄主义

## 2.6 SDD vs 传统开发

| 维度 | 传统开发 | SDD + AI |
|---|---|---|
| 文档 | 代码后补 | 文档先行 |
| 编码 | 手动 | AI 辅助 |
| 知识库 | 没人维护 | 持续沉淀 |
| 技术债 | 累积 | 可控 |
| 团队协作 | 靠沟通 | 靠文档 |

## 2.7 关键设计原则

1. **文档即契约**：代码必须符合文档
2. **AI 是工具**：AI 辅助，不是替代
3. **知识库是资产**：持续沉淀，不是一次性
4. **持续产出**：小步快跑，不是冲刺
