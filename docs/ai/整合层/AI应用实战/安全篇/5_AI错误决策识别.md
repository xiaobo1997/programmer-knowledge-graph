# §5 AI 错误决策识别：主动 + 被动发现

## 一句话摘要

AI 错误决策识别 的核心要点与实践指导。

**5W 速记卡**：
- **What**：AI 错误决策 = AI 做出错误判断
- **Why**：AI 错误决策 → 业务风险
- **Who**：开发者 + 运维 + 产品经理
- **When**：AI 执行决策时
- **Where**：业务系统

**自测三问**：
1. 本文核心机制：AI 决策 → 监控 → 识别 → 修正
2. 失效点：AI 错误决策 → 业务损失
3. 与下篇衔接：AI 错误决策 → 持续产出

---

## 5.1 思考：AI 决策会错在哪里？

**核心问题**：AI 决策会犯什么错误？

错误类型：
1. **逻辑错误**：AI 推理错误
2. **数据错误**：AI 基于错误数据决策
3. **上下文错误**：AI 缺少上下文做错误决策
4. **边界错误**：AI 在边界情况出错

## 5.3 逻辑错误

**逻辑错误是什么？**——AI 推理错误。

逻辑错误表现：
- 推理链条断裂
- 前提错误
- 结论错误

## 5.4 数据错误

**数据错误是什么？**——AI 基于错误数据决策。

数据错误表现：
- 数据过时
- 数据不完整
- 数据有误

## 5.5 上下文错误

**上下文错误是什么？**——AI 缺少上下文做错误决策。

上下文错误表现：
- 缺少业务上下文
- 缺少用户上下文
- 缺少时间上下文

## 5.6 边界错误

**边界错误是什么？**——AI 在边界情况出错。

边界错误表现：
- 极端输入
- 异常数据
- 边界条件

## 5.7 主动识别

**主动识别是什么？**——主动发现 AI 错误决策。

主动识别方法：
- 测试集验证
- 边界测试
- 红队演练
- 对抗测试

## 5.8 被动识别

**被动识别是什么？**——被动发现 AI 错误决策。

被动识别方法：
- 用户反馈
- 监控告警
- 日志分析
- 业务指标

## 5.9 识别实践

| 实践 | 做什么 | 优先级 |
|---|---|---|
| 测试集验证 | 验证 AI 决策 | P0 |
| 边界测试 | 测试边界情况 | P0 |
| 红队演练 | 模拟攻击 | P1 |
| 用户反馈 | 收集用户反馈 | P0 |
| 监控告警 | 监控异常 | P0 |

## 5.10 修正机制

**修正机制是什么？**——AI 错误决策后的修正。

修正方式：
- 自动修正（AI 自我修正）
- 人工修正（人工介入）
- 回滚修正（回滚到上一版本）

## 5.11 常见反模式

| 反模式 | 表现 | 代价 | 正确做法 |
|---|---|---|---|
| 无主动识别 | 只靠被动 | 发现慢 | 主动 + 被动结合 |
| 无被动识别 | 只靠主动 | 漏掉真实问题 | 主动 + 被动结合 |
| 无修正机制 | 错误不修正 | 风险累积 | 修正机制 |
| 无监控告警 | 异常不发现 | 问题积累 | 监控 + 告警 |

## 5.12 治理要点

**治理要点**：
- 主动 + 被动识别结合
- 修正机制兜底
- 监控 + 告警
