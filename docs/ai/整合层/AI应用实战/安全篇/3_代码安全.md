# §3 代码安全：AI 生成代码的安全风险

## 一句话摘要

代码安全 的核心要点与实践指导。

**5W 速记卡**：
- **What**：代码安全 = AI 生成代码的安全风险
- **Why**：AI 生成代码可能有漏洞
- **Who**：开发者 + 安全团队
- **When**：AI 生成代码时
- **Where**：代码仓库

**自测三问**：
1. 本文核心机制：AI 生成代码 → 安全审查 → 人工审核
2. 失效点：AI 生成漏洞代码 → 安全风险
3. 与下篇衔接：代码安全 → 信息暴露

---

## 3.1 思考：AI 生成代码的安全风险

**核心问题**：AI 生成的代码安全吗？

风险点：
1. **漏洞代码**：AI 生成有漏洞的代码
2. **依赖风险**：AI 引入不安全的依赖
3. **密钥泄露**：AI 生成包含密钥的代码
4. **后门代码**：AI 生成恶意代码

## 3.3 漏洞检测

**漏洞检测是什么？**——检测 AI 生成代码的漏洞。

检测项：
- SQL 注入
- XSS 攻击
- CSRF 攻击
- 缓冲区溢出

## 3.4 依赖检查

**依赖检查是什么？**——检查 AI 引入的依赖是否安全。

检查项：
- 已知漏洞依赖
- 过时依赖
- 不安全依赖

## 3.5 密钥检查

**密钥检查是什么？**——检查 AI 生成代码是否包含密钥。

检查项：
- API 密钥
- 数据库密码
- 私钥
- Token

## 3.6 后门检测

**后门检测是什么？**——检测 AI 生成的恶意代码。

检测项：
- 恶意代码
- 隐蔽逻辑
- 数据窃取

## 3.7 安全实践

| 实践 | 做什么 | 优先级 |
|---|---|---|
| 漏洞检测 | 检测 AI 生成代码的漏洞 | P0 |
| 依赖检查 | 检查依赖安全性 | P0 |
| 密钥检查 | 检查密钥泄露 | P0 |
| 后门检测 | 检测恶意代码 | P1 |
| 安全审查 | 人工审查 | P0 |

## 3.8 AI 辅助代码审查

**AI 辅助代码审查是什么？**——AI 帮你审查代码安全。

AI 辅助做什么：
- 自动漏洞检测
- 依赖安全检查
- 密钥泄露检测
- 后门代码检测

**核心原则**：AI 辅助审查 + 人工审核。

## 3.9 常见反模式

| 反模式 | 表现 | 代价 | 正确做法 |
|---|---|---|---|
| 无漏洞检测 | 漏洞代码上线 | 安全风险 | 漏洞检测 |
| 无依赖检查 | 不安全依赖 | 安全风险 | 依赖检查 |
| 无密钥检查 | 密钥泄露 | 安全风险 | 密钥检查 |
| 无人工审核 | AI 全权决定 | 误判 | 人工审核 |

## 3.10 治理要点

**治理要点**：
- AI 生成代码必须审查
- 漏洞检测 + 依赖检查 + 密钥检查
- 人工审核兜底
