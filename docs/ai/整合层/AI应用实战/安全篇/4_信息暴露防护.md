# §4 信息暴露防护

## 一句话摘要

信息暴露防护 的核心要点与实践指导。

**5W 速记卡**：
- **What**：信息暴露 = 敏感信息泄露
- **Why**：AI 工具可能泄露信息
- **Who**：开发者 + 安全团队
- **When**：使用 AI 工具时
- **Where**：企业内网 + AI 服务

**自测三问**：
1. 本文核心机制：信息暴露 = 敏感信息泄露 → 防护
2. 失效点：信息泄露 → 合规风险
3. 与下篇衔接：信息暴露 → AI 错误决策

---

## 4.1 思考：什么信息可能暴露？

**核心问题**：用 AI 工具时，什么信息会泄露？

泄露场景：
1. 代码中的密钥
2. 日志中的敏感数据
3. 文档中的内部信息
4. 数据库中的用户数据

## 4.3 敏感信息类型

**敏感信息类型**：
- 密钥（API 密钥 / 数据库密码 / 私钥）
- 用户数据（姓名 / 手机 / 邮箱 / 身份证）
- 业务数据（交易数据 / 账户数据）
- 内部信息（架构 / 接口 / 文档）

## 4.4 泄露途径

**泄露途径**：
- AI 工具上传（Copilot / Cursor / ChatGPT）
- 日志输出（日志包含敏感信息）
- 文档共享（文档包含内部信息）
- 代码提交（代码包含密钥）

## 4.5 防护措施

| 措施 | 做什么 | 优先级 |
|---|---|---|
| 密钥管理 | 密钥不硬编码 | P0 |
| 数据脱敏 | 敏感数据脱敏 | P0 |
| 日志过滤 | 日志不包含敏感信息 | P1 |
| 文档权限 | 文档权限控制 | P1 |
| 代码审查 | 审查密钥泄露 | P0 |

## 4.6 AI 工具场景

| AI 工具 | 泄露风险 | 防护措施 |
|---|---|---|
| GitHub Copilot | 代码上传 | 密钥检查 + 代码审查 |
| Cursor | 代码上传 | 密钥检查 + 代码审查 |
| ChatGPT | 文档上传 | 文档脱敏 + 审批 |
| Claude | 文档上传 | 文档脱敏 + 审批 |

## 4.7 检测机制

**检测机制是什么？**——检测信息暴露。

检测方式：
- 自动扫描（密钥扫描）
- 人工审查（代码审查）
- 审计日志（操作日志）

## 4.8 应急响应

**应急响应是什么？**——信息泄露后的响应。

响应步骤：
1. 发现泄露
2. 评估影响
3. 采取措施
4. 通知相关方
5. 复盘改进

## 4.9 常见反模式

| 反模式 | 表现 | 代价 | 正确做法 |
|---|---|---|---|
| 无密钥管理 | 密钥硬编码 | 泄露风险 | 密钥管理 |
| 无数据脱敏 | 敏感数据明文 | 泄露风险 | 数据脱敏 |
| 无日志过滤 | 日志包含敏感信息 | 泄露风险 | 日志过滤 |
| 无审计日志 | 操作不记录 | 无法追溯 | 审计日志 |

## 4.10 治理要点

**治理要点**：
- 敏感信息不暴露
- 密钥不硬编码
- 日志不包含敏感信息
- 操作有审计
