## 一句话摘要

安全篇帮助程序员治理 AI 应用中的信息审核风险、数据安全、代码安全、信息暴露和 AI 错误决策。

**5W 速记卡**：
- **What**：AI 安全 = 信息审核 + 数据安全 + 代码安全 + 信息暴露 + 错误决策
- **Why**：AI 应用有风险，需要治理
- **Who**：开发者 + 安全团队 + 运维
- **When**：使用 AI 时
- **Where**：业务系统

**自测三问**：
1. 本文核心机制：信息审核 + 数据安全 + 代码安全 + 信息暴露 + 错误决策

3. 与 SDD 篇衔接：SDD（怎么用） + 安全（怎么治理）

## 核心命题

> AI 是工具，但不是自解释的——怎么用、怎么治理、怎么发现问题。

## 7 篇核心内容

1. **信息审核风险** —— 误判 + 漏判 + 偏见 + 对抗样本
2. **数据安全治理** —— 数据分类 + 脱敏 + 权限 + 审计
3. **代码安全** —— AI 生成代码的安全风险
4. **信息暴露防护** —— 敏感信息泄露防护
5. **AI 错误决策识别** —— 主动 + 被动发现 AI 错误
6. **AI 执行可观测** —— Trace + 日志 + 指标 + 告警
7. **总结与展望** —— 回顾 + 展望 + 下一步行动

## 关键方法论

1. **主动 + 被动识别结合**：不只是被动等待，主动发现
2. **数据分类 + 脱敏 + 权限 + 审计**：数据安全四件套
3. **AI 生成代码必须审查**：AI 辅助 + 人工审核
4. **敏感信息不暴露**：密钥 + 数据 + 日志
5. **全链路可观测**：Trace + 日志 + 指标 + 告警
