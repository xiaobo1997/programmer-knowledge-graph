# §1 信息审核风险

## 一句话摘要

信息审核风险 的核心要点与实践指导。

**5W 速记卡**：
- **What**：信息审核风险 = 误判 + 漏判 + 偏见 + 对抗样本
- **Why**：AI 审核不可靠，需要主动 + 被动识别
- **Who**：审核工程师 + 产品经理
- **When**：AI 审核场景
- **Where**：业务系统

**自测三问**：
1. 本文核心机制：AI 审核 = 主动识别 + 被动识别
2. 失效点：AI 错误决策 → 误判/漏判
3. 与下篇衔接：信息审核 → 数据安全

---

## 1.1 思考：AI 审核的风险点

**核心问题**：AI 审核会犯什么错误？

错误类型：
1. **误判**（False Positive）：正常内容判为违规
2. **漏判**（False Negative）：违规内容判为正常
3. **偏见**（Bias）：对某些群体不公平
4. **对抗样本**（Adversarial）：故意绕过审核

## 1.3 误判（False Positive）

**误判是什么？**——正常内容被判为违规。

误判表现：
- 正常文本被判为敏感
- 正常图片被判为违规
- 正常视频被判为违规

误判代价：
- 用户体验下降
- 业务损失
- 信任下降

## 1.4 漏判（False Negative）

**漏判是什么？**——违规内容被判为正常。

漏判表现：
- 违规文本通过审核
- 违规图片通过审核
- 违规视频通过审核

漏判代价：
- 合规风险
- 法律风险
- 品牌风险

## 1.5 偏见（Bias）

**偏见是什么？**——对某些群体不公平。

偏见表现：
- 对某些语言不公平
- 对某些地区不公平
- 对某些用户不公平

偏见代价：
- 合规风险
- 品牌风险
- 用户流失

## 1.6 对抗样本（Adversarial）

**对抗样本是什么？**——故意绕过审核。

对抗样本表现：
- 变体文本（谐音/拆字）
- 变体图片（滤镜/遮挡）
- 变体视频（剪辑/加速）

对抗样本代价：
- 审核失效
- 合规风险
- 品牌风险

## 1.7 主动识别

**主动识别是什么？**——主动发现 AI 审核的错误。

主动识别方法：
- 定期测试（测试集）
- 人工抽检（人工审查）
- 红队演练（模拟攻击）

## 1.8 被动识别

**被动识别是什么？**——被动发现 AI 审核的错误。

被动识别方法：
- 用户反馈（用户举报）
- 监控告警（异常检测）
- 日志分析（事后分析）

## 1.9 治理要点

**治理要点**：
- 主动识别 + 被动识别结合
- 误判 + 漏判平衡
- 偏见监控 + 对抗防御
- 人工复审兜底

## 1.10 常见反模式

| 反模式 | 表现 | 代价 | 正确做法 |
|---|---|---|---|
| 无主动识别 | 只靠被动 | 发现慢 | 主动 + 被动结合 |
| 无被动识别 | 只靠主动 | 漏掉真实问题 | 主动 + 被动结合 |
| 无人工复审 | AI 全权决定 | 误判/漏判 | 人工兜底 |
| 无监控告警 | 异常不发现 | 问题积累 | 监控 + 告警 |
