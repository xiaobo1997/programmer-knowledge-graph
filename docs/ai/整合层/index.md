# 整合层

## 一句话摘要

整合层是 AI 知识图谱的高阶实践层——覆盖 agent 实战 + AI 应用实战（SDD + 安全）。

**5W 速记卡**：
- **What**：整合层 = agent 实战 + AI 应用实战
- **Why**：入门层讲是什么，整合层讲怎么用 + 怎么治理
- **Who**：做了 agent 的工程师 + 用 AI 开发的团队
- **When**：已有入门层基础，需要实践指导时
- **Where**：团队 + 个人

**自测三问**：
1. 本文核心机制：agent 实战 + AI 应用实战
2. 失效点：只懂理论不会实践
3. 与入门层衔接：入门 → 整合 → 专题

## 核心命题

> agent 治理不是「加个 sandbox 就完事」——6 层协同 + 业务场景落地。
> AI 是工具，但不是自解释的——怎么用、怎么治理、怎么发现问题。
